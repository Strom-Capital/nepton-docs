# Työajan liittymien API

Tässä artikkelissa kuvataan Työajan liittymien API:n menetelmiä työajan integraatioiden käsittelemiseksi.
## Liittymän siirtotiedoston hakeminen
Palvelun kautta on mahdollista ajaa Neptoniin lisätty sääntöjoukko ja saada sen data halutussa formaatissa (esim. CGI Palkat aineisto).
API-metodit:
  * [RunIntegrationRuleSet (vanhentunut)](<https://support.nepton.com/hc/fi/articles/6881855535773>)
  * [RunIntegrationRuleSetV2](<https://support.nepton.com/hc/fi/articles/360014449458>)
