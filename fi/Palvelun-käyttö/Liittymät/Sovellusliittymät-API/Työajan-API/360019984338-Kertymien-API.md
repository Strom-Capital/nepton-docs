# Kertymien API

Tämä artikkeli kuvaa [Työajan API](<https://support.nepton.com/hc/articles/360004861558>) menetelmät kertymiin liittyen.
## Käyttäjän kertymien hakeminen
Palvelun kautta on mahdollista hakea henkilön kertymien arvot tietyiltä päivämääriltä sekä muutos aiempaan päivään nähden
API-metodi, jolla voi hakea kertymiä:
  * [GetAccrualValuesForUser](<https://support.nepton.com/hc/fi/articles/6913825701277>)
