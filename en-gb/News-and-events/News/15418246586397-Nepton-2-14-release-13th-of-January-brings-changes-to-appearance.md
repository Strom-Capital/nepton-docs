# Nepton 2.14 release 13th of January brings changes to appearance

**The scheduled release date for Nepton's next minor release is set for January 13th 2024. Changes to the release date and scope are possible.** You can always find up-to-date information about release date on the [Platform Status page](<https://support.nepton.com/hc/en-gb/articles/360006554777>). The exact content of the release will be updated to [Release Notes](<https://support.nepton.com/hc/en-gb/articles/360006615478>) closer to the release date. Version 2.14 brings improvements to Nepton's interface, the ability to measure user satisfaction and the first section of accruals updates.
**Enhancements to the Worktime Calendar View**
The layout of the calendar view has been improved, with comprehensive explanations added for the different colors on the calendar. Quick start events familiar from mobile devices have been added into the Calendar view. Quick starts can be displayed by pressing the desired day on the calendar. Additionally, the option to continue past events has been added. When selecting a past event, the Continue button is displayed.

**Interface Update for Worktime Current Status View**
The layout of the current status view has been completely redesigned to match the overall interface of the service. In addition, the current status view offers the same functions for adding events as the calendar and mobile views.
![uusi-nykytila.png](https://support.nepton.com/hc/article_attachments/15418515158045)
**Appearance Update for Nepton's Top Menu**
The layout and functionality of Nepton's top menu are being updated. User account related functionalities will be placed in the top right corner of the menu. Also, a new functionality for collecting customer feedback will be located in the top menu.
**Collecting Feedback within Nepton**
Starting in early 2024, we will begin collecting regular feedback on the Nepton service. Feedback will be gathered directly through the Nepton interface via NPS surveys and open feedback. We want to ensure a smooth employee experience for our customers and improve the quality of our services. Feedback will be utilized in product development.
**Diversification of Accruals**
Accruals will be revamped in the spring, with the first part of this development released in January. We will add support for holiday compensation leave, generic bank, and savings leave. We will also add support for creating and naming your own accruals.
**Updates to Weekly Rest Compensation**
There have been updates to weekly rest compensation in the fall, and these will continue in the spring. We recommend reviewing the already implemented updates through the support service's [Release Notes page](<https://support.nepton.com/hc/en-gb/articles/360006615478>).
**Please note that changes to the release date and the content described here are possible.**
