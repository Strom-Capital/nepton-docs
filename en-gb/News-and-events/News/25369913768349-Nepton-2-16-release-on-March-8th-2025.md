# Nepton 2.16 release on March 8th 2025

Nepton's next major release will take place on Saturday, March 8, 2025. Please note that there may be changes to the release date and content. You can always find the latest information about the release date on the [Platform status page](<https://support.nepton.com/hc/en-gb/articles/360006554777>). Whole release content can be found from the [Release notes](<https://support.nepton.com/hc/en-gb/articles/360006615478>).
## Changes to report appearance and names
The appearance of report views has been updated to match Nepton's new styling, and the names of reports have been standardised and clarified. The new names now better reflect the content of the reports. The names of the reports will change as follows:
Report type | Old report name | New report name  
---|---|---  
Work hours reports | Annual leave, usage follow-up | Annual leave usage by season  
| Annual leave, rolling month analysis | Annual leave usage by month  
| Annual leave, earned days | Annual leave earning by month  
| Sick leaves per person | Sick leaves by person  
| Sick leaves per group | Sick leaves by person group  
| Absences per person | Absences by person  
| Balance events | Managerial balance changes  
| Event report | Event listing  
| Overtime report | Overtime hours by person  
| Dining sum up report | Dining sum up by person  
| Dining report | Dining by person  
Project reports | Project overtime report | Project overtime hours  
| Project invoicing report | Project work sum up by person  
## Custom reports
Create reports based on your choice of Nepton data, with the option to also share these reports with others in your organisation. The custom report feature is part of the new paid Insights service, which offers broader reporting options than the standard reports. Please reach out to our specialists to learn more!
## Improvements to accruals
We have made significant improvements to accrual management and unified their technical implementation, enabling more flexible use in various use cases. This changes how accruals function:
  * **All leave days related to accruals** (e.g., holiday pay leave, time-off leave) are now handled as accrual leave, regardless of whether the accrual is in use. This may impact reporting and export data.
  * **Accrual balance reset event types** will now be applied at the beginning of the day for all accruals, even in the past. Accrual balance change events at the end.
  * **The handling of balance limits and max** time has been improved, and the part exceeding the accrual limit can now be transferred to another accrual or paid out in payroll.
  * **Customised accruals** now better support monthly accrual tables, such as annual leave accruals.


## Real-time data transfer to payroll
Nepton’s new technical solution enables the real-time transfer of absence data to payroll systems, even via an SFTP server. Initially, this can be used with Accountor Mepco HRM for absence exports, but it will be available for other systems in the future.
## Improved usability of setting groups
Worktime settings default and inherited values are now visualised so the effective value can easily be seen at all levels. Long field listing is no longer shown with work rises. Work rises will only show up to the work rise number that has settings. The new "Add work rise" button can be used to add work rises.
## User interfaces improved
We have begun the use of a new framework for the development of our user interface. As a result, there will be many subtle differences in the appearance of the service in this version. In the future, this help speed development and standardisation.
## Technical development and performance improvements
We’ve updated Nepton’s technical platform to improve service stability, security, and performance. With these updates, Nepton will run more smoothly and be up to date with the latest technology. Time management, shift calendars, and balancing periods now work faster and more efficiently. In addition, The Nepton touch terminal application performance and security have been improved by migrating to the .NET 8 framework. This change affects all Nepton Touch devices issued after September 2022.
