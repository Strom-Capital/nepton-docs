# Nepton release on September 20th brings improvements to shift planning

The next major Nepton update will be released on **Saturday, 20th of September 2025.** Please note that the release date and contents are subject to change. You can always find the most up-to-date information on the [Platform status](<https://support.nepton.com/hc/fi/articles/360006554777-Palvelun-tila>) page, and the full release details are available in the [Release notes](<https://support.nepton.com/hc/fi/articles/360006615478-Julkaisutiedotteet>).
This update includes several improvements requested by shift planners, aimed at making their work easier, along with other minor enhancements.
## Year targets in shift planning
A new Year target setting has been added to the Worktime settings. It allows you to define a year target in hours, which is particularly useful in industrial companies. The setting can be applied at either setting group or individual level.
This data can be used in shift planning. When planning shifts, you can instantly see the total hours of scheduled shifts and how they compare to the year target.

## Overhauled messaging features in shift planning
Communication related to shifts has been enhanced:
  * Shift planners can now view all shift reservations and related messages in the new Messages view, located at the top of the planning view.
  * Planners and employees can discuss shift-related matters directly via the Messages feature.
  * Employees can send a message by opening a shift in the Worktime view and typing into the new Message field.

![](https://support.nepton.com/hc/article_attachments/30116279599133)
## New permission for assigning shift templates to locations
Planners can be granted permission to define which locations shift templates are available in. This permission is managed via permission groups. Once granted, planners can select applicable locations directly within the shift template editing view.
This change simplifies the planner’s workflow and reduces reliance on administrators. Location assignment is now handled directly within the template, making management faster and more intuitive.

## Other improvements to shift planning
  * The layout and terminology in several planning views have been clarified.
  * Filtering options in the planning view have been improved.
  * Creating and managing shift templates is now easier.
  * Templates can now span multiple days.
  * A new field, “Planner notes”, supports collaboration between multiple planners and is not visible to other users.
  * The behaviour of different shift types has been standardised, and overall performance in shift planning has been improved. 

![](https://support.nepton.com/hc/article_attachments/30116249105565)
## Translations for quick start events and absence types
It is now possible to add translations in multiple languages for:
  * Quick start events
  * Customer-specific absence types


This removes the need to manually include translations in event names (e.g. “Work / Työ”). Broader translation support is especially helpful for organisations operating in multiple countries.
## Changes to worktime settings are logged in the service log
From now on, all changes made to worktime settings will be automatically saved in the service log. Each change can include a written reason for the change. Administrators can choose to make providing a reason mandatory in the working community settings, enhancing transparency and traceability.
Logging will be enabled automatically for all customers whose onboarding was completed at least six months ago. For new customers and those still in the onboarding process, logging will be activated once the worktime settings have been fully configured.
