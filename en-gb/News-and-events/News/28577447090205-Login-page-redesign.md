# Login page redesign

This article contains information about the release on 9 August 2025. 
Nepton’s next major update will be released on Saturday, 9 August 2025. Please note that the release date and contents are subject to change. The most up-to-date information about the release schedule can always be found on the [Platform status page](<https://support.nepton.com/hc/en-gb/articles/360006554777>). The full content of the release is available in the [Release notes](<https://support.nepton.com/hc/en-gb/articles/360006615478>).
As part of the update, the appearance of the login page will be refreshed, and it will also become possible to enable login using an RFID tag on workstations.
## Login page appearance update
As part of the ongoing renewal of Nepton’s user interface, the appearance of the login page will be updated. The new login page will have a lighter and more streamlined appearance. A separate notice about this change will be published on the current login page before the update, so that users are informed.
![](https://support.nepton.com/hc/article_attachments/29020026835869)
## RFID login on desktop version
After the update, it will be possible to enable login using an RFID tag in the desktop version of Nepton. To enhance security, employees will be required to enter a personal PIN code in addition to scanning their tag.
This is a suitable solution, for example, when employees are expected to log their working hours on a shared computer located at the workplace. Enabling this feature requires an RFID reader to be connected to the computer.
