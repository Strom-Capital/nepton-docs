# Person information change log

A person with Administrator, HR Management or Salary Management role can see the person information change log. In the change log, you can see the changes made to people's information, the time of the change, who's done the change, and the effective date of the change.
The personal data change log can be found: **Employees > Administration > Person information change log.**
![](https://support.nepton.com/hc/article_attachments/19306503026589)
The search results can be filtered by time selection, target person or the changed field.
![](https://support.nepton.com/hc/article_attachments/19306478499357)
The following fields are not shown in the change log: unit, setting group, worktime percentage, worktime role, person group, subordinates, supervisors, person list and primary task.
In the picture below is an example person Ukko Pakkanen's change log from the day the user was created. 
Ukko was created on 9.2.2024 by Nepton Admin. Therefore there is no information before this date. All fields filled when created are seen with the date 9.2.2024.
On 4.6.2024 Ukko's information has been changed:
  1. Pin-code is set with the validity control.
  2. The language is changed to English, without the validity control, so the old value has been replaced with the nee value.
  3. Default project is added.


![](https://support.nepton.com/hc/article_attachments/19306478509085)
All changes have been made by Nepton Admin. If there would be any changes made by scheduled integration, the "changed by" would show a user called "Person import" or similar to indicate that it was made by integration.
