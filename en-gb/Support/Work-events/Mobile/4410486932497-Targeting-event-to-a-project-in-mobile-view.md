# Targeting event to a project in mobile view

Project targeting can be taken into use in Pro and Complete service levels.
Start an event by clicking on the orange + sign at the bottom of the page. An Add event window will open. If the event has already been started, click on the event to open an Edit event window.
![](https://support.nepton.com/hc/article_attachments/35277094762141)
The event can be targeted to several projects. Work targeted to several projects can be divided by using percentages or hours. More details about project targeting can be found [here](<https://support.nepton.com/hc/en-gb/articles/360002596797>).
Each project has internal and public notes fields for additional information, if enabled in the settings.
![](https://support.nepton.com/hc/article_attachments/35277094763805)  
Once the correct information has been filled, click **Save**.
Now the event has been started. It shows in mobile front page and the targeted projects are shown below the event name.
![](https://support.nepton.com/hc/article_attachments/35277091189277)
If an assumed lunch break is in use, it will not be assigned a project. If you want to assign a project to lunch break, it must be done manually.
