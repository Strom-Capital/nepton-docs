# Adding events in Nepton mobile

Nepton mobile is accessed at https://go.nepton.com/. The same address is also used in the desktop version. The address can be saved, for example, to the bookmarks of your phone's web browser or as a shortcut, making it easy to use.
There are two ways to start an event on the mobile website. The **quick start** allows you to start basic events with a single button, and if you want to edit the event type, time or project, for example, this can be done via a separate **Add Event** button (orange +).
## Quick Start
When you open the Mobile page, the service offers [Quick Starts](<https://support.nepton.com/hc/en-gb/articles/7074461491101>) by default. With Quick Start, you can start defined events with pre-filled informations. By default, work and lunch are offered as quick starts. To start the event, press the **Start** button.
![mceclip1.png](https://support.nepton.com/hc/article_attachments/360018305017)
When an event is logged using quick start, the event start time will be the time the Start button is pressed. If the user has a default project, the event will automatically be logged to it.
If you want to start another event after starting an event, all you have to do is press the Start button in the Quick Start view. This will automatically end your previous event, meaning you don't have to stop the current event separately. At the end of the day, it is possible to end an active work event (or any other event) in the quick start view with the Stop button.
An event made in the past can also be continued quickly by clicking the Continue button next to it:![](https://support.nepton.com/hc/article_attachments/19004301587741)
In this case, an event exactly the same as the one that was continued will be logged for the current day starting from that time. This can speed up logging events, for example, when the event is targeted to a project. When using the Continue function, all information from the event is also logged to the new event, including projects and supplements.
## Starting an Event by "Add Event"
The **Add event** button makes it possible to select different types of events, edit the time of the entry, change the project and, for example, add supplements to the event.
**Please note!** If you have only the permission to report own real time events (no permission to edit events), you can only start events with the quick start buttons. User permissions might also limit setting overtime options and adding supplements.
To add an event for the current day, select the orange 'plus' sign at the bottom of the page.
![mceclip2.png](https://support.nepton.com/hc/article_attachments/360018305037)
The Add Event window will then open.
Select the event type, start and end times and, if necessary, projects, overtime target and / or supplements. It is also possible to write a comment in the Notes field. 
![](https://support.nepton.com/hc/article_attachments/35274399460509)
When pressing the green arrow, the start time will become current time and end time will be removed.
![](https://support.nepton.com/hc/article_attachments/35274386689821)
When the correct information is entered, click **Save**.
Now that the work event has started, it will appear on the front page (the Quick Start page). In this view, it is possible to end the event with the Stop button.
![mceclip5.png](https://support.nepton.com/hc/article_attachments/360018305157)
## Starting an event from a work shift
If there is a work shift on the day, it is possible to start an event based on the work shift.
Starting a real-time event from the work shift can be done from pressing the Start button next to the shift.
![mceclip2.png](https://support.nepton.com/hc/article_attachments/4927126142237)
Or by clicking the shift, an event edit window opens up. By default the start and end times are based on the planned shift. By saving the event, a work event based on the shift has been added.
![mceclip3.png](https://support.nepton.com/hc/article_attachments/4927169442717)
