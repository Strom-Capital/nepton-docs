# Mobile view

This article explains what information is displayed in the mobile view. The numbers in the upper right corner of the mobile view indicate the following:
1\. Value 16:30 - hours worked during the mobile view period (Mon-Sun), including absences.  
2\. Value +0:00 - over/under regular working hours during the mobile view period (Mon-Sun)  
3\. Value 49:54 - total value of balance (if balance is in use)  
4\. Value +0:00 - balance change happened on the current day (if balance is in use)
In the mobile view, it is possible to view only balance accrual value. Other accruals, such as bank, are currently not visible in the mobile view.
![](https://support.nepton.com/hc/article_attachments/35247949980829)
An event can be started either via Quick or by + button. More information about registering work hours in mobile [here](<https://support.nepton.com/hc/en-gb/articles/33667266972701>).
In the top right corner there is a calendar icon, which opens up a wider range of dates to select.
