# Deleting an event in Nepton mobile

Deleting an event is also possible on Nepton mobile.
Select the day from which you want to delete an event.
![](https://support.nepton.com/hc/article_attachments/20264702967581)  
  
  

  
Select the Event by clicking on the title. The view that opens up has a bin icon on the top left corner.
![](https://support.nepton.com/hc/article_attachments/20264719902365)  
  
  
  
To delete the event, simply click on the bin.
System confirms this. Click "Ok" and the event has been deleted and the view will return back to the main mobile view.
![](https://support.nepton.com/hc/article_attachments/20264719907229)
