# Event edit history & restoring deleted events

All changes made to events are saved in their history, which can be viewed and used to restore the event to an earlier version. 
## Event history
The history of all recorded events is stored in the service. Even if an event is edited, you can view the original entry through the event history. The event history can be viewed either in the calendar view or in the [event listing report.](<https://support.nepton.com/hc/en-gb/articles/360002548877>)
### Calendar view
Event history can be opened by clicking on the work entry. In the pop-up window that opens, select the **Edit History** option.
![](https://support.nepton.com/hc/article_attachments/35188329787933)
This will open a new pop-up window showing all previously existed versions of the event. The view shows the event type, the creater, when the event was created, and whether it was approved or deleted. Approving an event or its projects creates a new row of the event, where the creation/modification time is the time of approval. A lock icon is displayed in the 'Is Approved' field on the row if the event has been approved.
![](https://support.nepton.com/hc/article_attachments/35188337149085)
The **View** button opens the event window with information from that historical moment for more detailed review.
![](https://support.nepton.com/hc/article_attachments/35188337151389)
### Event Listing
All changes made to an event and deleted events can be seen in the calendar view as well as in [the event listing report](<https://support.nepton.com/hc/en-gb/articles/360002548877>). 
## Restoring events
In the calendar view, active events can be restored to a previous version. If an event has already been deleted, it can be restored back to active via the [Event listing report](<https://support.nepton.com/hc/en-gb/articles/360002548877>).
### Calendar view
In the calendar view, you can restore an event to any previous version. First, open the event history, and in this view, use the magnifying glass to select the version you want to make active. When a version that is not the latest version of the event is open, this information is highlighted in yellow at the top of the window. The **View latest** button takes you to the current version of the event. The **Restore** button can be used to revert the current version to the version that is currently open.
![](https://support.nepton.com/hc/article_attachments/35188329790877)
If the view is open, but you only want to view it and not activate the old event version, you can use the **Go back** button to return to the previous view without making any changes.
### Event Listing
Through the Event Listing report, an event can be restored to its previous version in the same way as through the calendar view. The event is opened from the report by clicking on the event type name, which opens a new window listing all versions of the event. When the desired version is opened using the magnifying glass, the information for that version opens and the Restore button appears at the top.
![](https://support.nepton.com/hc/article_attachments/35188337153693)
![](https://support.nepton.com/hc/article_attachments/35188329796509)
The event listing also lists all deleted events, if this has been selected in the filters when retrieving the report. If an event has been deleted, its details are displayed in gray, and the "deleted" column reads "yes".
![](https://support.nepton.com/hc/article_attachments/35188337155741)
However, the same actions can be done for a deleted event as for an active one. The event is opened by clicking on the event type, which allows you to see the familiar route and restore its previous versions.
