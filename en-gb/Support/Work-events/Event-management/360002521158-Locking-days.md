# Locking days

Locking or removing locking from days is possible only for Nepton admin user. Find more about permissions [here](<https://support.nepton.com/hc/en-gb/articles/360002554338>)
Days can be locked, after which the events on them can no longer be edited by employees. The functionality can be used, for example, when the hours have already been transferred to payroll. NOTE: Once a day is locked, new events cannot be added to the entire day except by the administrator. An exceptional setting can not be done either, unless the person has the right to unlock days.
If a deviant Work week starting time is used (other than 00:00), this also applies to the locking.
## Permission for locking
Locking days can be done by anyone who has the right to lock days based on their worktime role. The right to lock and unlock days can be found in the rights of the higher-level working time role:
![](https://support.nepton.com/hc/article_attachments/35179737648797)
**Can lock event dates** permission grants the right to lock days when they are approved.
**Can unlock locked dates** grants the right to unlock days. This is usually granted only for the administrator, but if necessary, can be given to other users..
## Manual locking
### Locking days
Days can be locked in **Worktime > Tools > Mass set event locking dates**: 
![](https://support.nepton.com/hc/article_attachments/29569391551517)  
Events can be locked to any date in the future. To change the locking date for already locked days, set the **Select locking date** to the day until which the days are to be locked, for example to the end of last payroll period.
![](https://support.nepton.com/hc/article_attachments/29569355920541)
The locking can be done for one individual person, a whole person group or all personnel. By default, users are searched for within the last year. The time period and other settings for selecting users can be edited using the cogwheel icon. When the correct users are selected, click **Set locking dates**. 
Once locking is done, an image of a lock will appear in person's calendar indicating that the day is locked.
![](https://support.nepton.com/hc/article_attachments/21978936083869)
### Unlocking days
Removing locking can be done in **Worktime > Tools > Mass set event locking dates**: 
![](https://support.nepton.com/hc/article_attachments/29569391551517)
Removing locking can be done by leaving **Set locking dates** empty, choosing the correct users and then clicking **Set locking dates**. The locking can be removed for one individual person, a whole person group or all personnel.
![](https://support.nepton.com/hc/article_attachments/29569355920541)
When 'Set locking dates' is clicked, locking will be removed for the selected persons from the history. 
Image of the lock will disappear from persons' calendar dates, which are not locked anymore.
![](https://support.nepton.com/hc/article_attachments/21978936087069)
## Automatic locking of events
Automatic locking of events can be set in **Worktime > Administration > Working community settings/Setting group settings > Work hours > Event locking and approval > Lock events automatically after.**
Automatic locking takes place at 00:30.
![](https://support.nepton.com/hc/article_attachments/29569391556637)
