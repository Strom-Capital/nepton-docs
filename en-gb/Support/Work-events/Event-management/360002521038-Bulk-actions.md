# Bulk actions

If there is a need to edit or delete multiple events, **Bulk actions** -tool can be used. Go to Worktime > Work hours > Events in calendar.  
![](https://support.nepton.com/hc/article_attachments/35069362529053)
When bulk actions are activated, a check box will appear for each week, day, and event. Events can be selected for editing on a week, day, or event-by-event basis.
![](https://support.nepton.com/hc/article_attachments/35069338127901)
When the events selected for editing are checked, the desired action is selected at the bottom of the view. The employee can delete the selected events, or edit their project allocation. The administrator or supervisor can also approve the events (without locking).
![](https://support.nepton.com/hc/article_attachments/35069362529821)
If you edit the project targets of the selected events, the **Edit Projects** button will open a pop-up window where you can change the project targets.
![](https://support.nepton.com/hc/article_attachments/35069338129181)
In the**Select projects** part project targets for events can be replaced with other projects, or new projects can be added to the event. Each project duration can be edited to the wanted length. 
In **Review events** part you can also separately select which events the project targeting will be changed to (check the box).
Finally, choose to either **Override existing projects** or **Add to existing projects** to the event in addition to existing projects.
