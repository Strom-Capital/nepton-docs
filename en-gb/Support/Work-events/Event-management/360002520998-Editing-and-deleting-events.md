# Editing and deleting events

Events recorded to calendar in **worktime** can be flexibly edited. Events can be edited in calendar and table view or individually in [mobile view.](<https://support.nepton.com/hc/en-gb/articles/360002602658-Edit-events-using-Nepton-mobile>)
In this article, editing a single event is guided. If you need to edit multiple events at one time, please see [this article](<https://support.nepton.com/hc/en-gb/articles/360002521038>).
If there is a need to change an already recorded event afterwards, this is possible. Rights to edit events are given by the worktime role, so depending on the policies, different users may have different rights to edit the event. The most common policy is that employees can edit events until they are approved by a supervisor. After approval, the supervisor can edit events until the days are locked. After locking, only the administrator can edit events. If a person has the right to edit an event, they can also delete events.
Calendar view can be found in **Worktime > Work hours > Events in calendar**.
## Editing an event
To edit an event, click on the event in the calendar, and the menu below will open:  
  
![](https://support.nepton.com/hc/article_attachments/35048097358109)  
Click **Edit** and the event edit window will open in a separate window:   

![](https://support.nepton.com/hc/article_attachments/35048114081437)
The event can be flexibly edited:   
  
\- Used Event type  
\- Start and End time of the event  
\- How to process overtime after regular worktime  
\- Supplements  
\- Project targets  
\- Attachments (if enabled for deployment)  
\- Comments  
  
Editing options change between different event types, depending on if the event is for example Work - or Absence event type. Also company specific configurations might affect to the editing options.
Note that after editing or saving a new event, if the event would have a potential issue like e.g. it overlaps another event or its project hours are not allocated correctly within the event's duration, a warning will be displayed when saving the event. 
![](https://support.nepton.com/hc/article_attachments/35048114084125)
Event may be saved with these warnings by clicking "Yes" or the event can be modified/updated based on the details related to these warnings by clicking "Cancel" and then editing the event details. If an event is saved despite the warning, a yellow warning triangle will appear in the calendar view, indicating an exceptional entry. Exceptional entries can be managed and turned on or off [in the settings](<https://support.nepton.com/hc/en-gb/articles/360002560618>).
![](https://support.nepton.com/hc/article_attachments/35048097366941)
All event editing data is saved to [history data.](<https://support.nepton.com/hc/en-gb/articles/360002521298-Event-edit-history>)
## Deleting an event
Events can be deleted in the calendar view through the same menu as when editing them. Click on the event to open the menu. From the menu, press "delete":
![](https://support.nepton.com/hc/article_attachments/35048393674397)
After clicking on this, you will need to confirm the deletion via a new pop-up window:
![](https://support.nepton.com/hc/article_attachments/35048386149917)
Once an event is deleted, it disappears from the calendar view. Deleted events can still be viewed and restored to active status via the [Event Listing report](<https://support.nepton.com/hc/en-gb/articles/360002548877>).
