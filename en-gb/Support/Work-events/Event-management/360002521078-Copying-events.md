# Copying events

It is possible to copy events via the Copy function in the calendar view (Worktime > Work hours > Events in calendar).
Copying can be useful, for example, in a situation where a person's work entry is exactly the same every week on the same day, or if the entire staff has a common training day and it should be recorded uniformly for everyone.
## Copying events for one or multiple users
Copying is done by clicking on the event you want to copy. Select "copy" from the menu that opens.
![](https://support.nepton.com/hc/article_attachments/35052197695389)  
  
A new pop-up window will open with the copying options. At the top, you will see which event is being copied. Next, you will define the time period to which the event will be copied. Below this, you will select whether to repeat the copying. Note that you cannot leave the selection blank, or the copying will not take place. Under Frequency, there is a checkbox that you can tick to specify whether to skip holidays or whether to copy the event to them as well, if they fall within the selected time period.  
![](https://support.nepton.com/hc/article_attachments/35052173512349)
Once the selections related to the time frame of the copying have been made, the users or user groups to whom the entry is to be copied to are selected. The person selections can also be limited by other criteria than the person group, by using the gear wheel in the upper right corner. More information about the person restrictions that can be used is available [here](<https://support.nepton.com/hc/en-gb/articles/360004437597>).
![](https://support.nepton.com/hc/article_attachments/35052197697181)
Finally, click **Copy event** at the bottom of the page.
When the copy is complete, a summary will open. In the view, you can view the copies made at the person level by clicking "Click to view" in the breakdown section. If you notice any errors, you can use the remove mistakes function to mass delete the events that have just been copied. By clicking the Copy to other button, you can return to the first page of the copy to select the time period and persons and possibly make a new copy. If you are satisfied with the result of the copy, you can close the view by clicking the Close button.
![](https://support.nepton.com/hc/article_attachments/35052197697949)
Approval of an event or event request does not transfer to the copied events.
## Frequency
**Daily** creates event to all dates during the given period of time. 
**Work days** creates events from Monday to Friday during the given period of time.
**Weekly** creates event for example to every week Mondays. The first day of the time period needs to be Monday where the event wants to be copied to and last day needs to be Monday where the event wants to be copied to. Nepton creates copy of the event to each Monday during the given period of time.
**Monthly** creates event once a month starting from the given period of time. If give 'First entry' date is 20.6. and 'Repeat until' date is 31.8., Nepton adds the copied event to dates 20.6, 20.7. and 20.8.
**Monthly on same week day** creates event once a month to the week day which 'First entry' date is given. If the given 'First entry' date is Sunday 3.6. and 'Repeat until' date is 15.9. Nepton adds the the copied event to each Sunday during the given period of time. 
**Yearly** creates copied events once a year. If the 'First entry' is given 1.1.2018 and 'Repeat until' date is 31.12.2020, service creates copied events to 1.1.2018, 1.1.2019 ja 1.1.2020.
## Undoing copying
Copying events can be undone right after copying in the Copy event view by pressing **Remove mistakes:**
![](https://support.nepton.com/hc/article_attachments/35052173514013)
Next, tick the events to be deleted and press 'Delete events':
![](https://support.nepton.com/hc/article_attachments/35052197699741)
If the copy view is already closed, all events made from copies can still be found in the calendar view. Click on the original event, which will open a menu. From here, select "related events":
![](https://support.nepton.com/hc/article_attachments/35052173517469)
This opens the same window as the Remove Mistakes button in copying. The desired events can be selected as active and deleted:
![](https://support.nepton.com/hc/article_attachments/35052197700765)
Mass deletion for copied events can be done as long as the events are not edited or approved.
