# Adding, enabling, and editing absence types

Nepton has dozens of different standard event types. One of the event types is Absence, under which absence types can be defined. When absence types are set to absence event type, they are shown as list when adding new Absence event.
![](https://support.nepton.com/hc/article_attachments/32930535263517)
This article describes how you can add, enable and edit absence types in Nepton.
The entries made will remain in the service, even if the absence type is later deactivated.
### Default absence types
The service comes with a set of absence types that are available to everyone.
![Näyttökuva 2025-11-25 kello 15.42.39.png](https://support.nepton.com/hc/article_attachments/32057429974301)
### Adding absence types
Adding new absence types is done in Working community settings (**Worktime > Administration > Working community settings > Work hours > Absence types**). 
Click **Add absence type**.
![Näyttökuva 2025-11-25 kello 15.43.25.png](https://support.nepton.com/hc/article_attachments/32057429975965)
Enter **Name** for the absence type. Name is shown in adding and editing window when event type is chosen as Absence. 
The name can be translated into every language used in the organisation. This way, the absence type is displayed according to the user's language preference. By clicking the **Other languages** button, you can add translations for different languages
Select the wanted **Compensation type default**. This defines, if absence type is paid, unpaid, or reduced salary as default. 
Select if absence type **Earns vacation days default**.
Click **Add**
![Näyttökuva 2025-11-25 kello 15.45.03.png](https://support.nepton.com/hc/article_attachments/32057429977245)
![Näyttökuva 2025-11-25 kello 15.45.20.png](https://support.nepton.com/hc/article_attachments/32057460992669)
When new absence type is added, it will be shown in listing. It also automatically generates a code. Code can be used to define [exceptions to settings](<https://support.nepton.com/hc/en-gb/articles/360002560677-Configure-exceptions-to-settings>) or in [integration rulesets.](<https://support.nepton.com/hc/en-gb/articles/360002489257-Setting-up-integration-rulesets>)
### Enabling absence types
Absence type can be enabled by selecting '**Yes** ' in the '**In use** ' column. By default, All listed absence types are in use and shown when adding new Absence event. 
![Näyttökuva 2025-11-25 kello 15.48.04.png](https://support.nepton.com/hc/article_attachments/32057460994973)
### Editing Absence type
Absence type calculator behavior can be edited. Editing is possible but editing values in columns '**Compensation type defaul** t' and '**Earn vacation days default** '. New value is valid once setting is saved. Default setting to each absence type listed can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360002519937-Absence-type-management>)
Name of the new absence type created to Nepton can be edited as well as the translations of the name. Default absence type names cannot be edited. Editing is possible by clicking blue pen icon.
![Näyttökuva 2025-11-25 kello 15.50.02.png](https://support.nepton.com/hc/article_attachments/32057460996509)
New name is added to the name field. You can also edit other fields in this view.
![Näyttökuva 2025-11-25 kello 15.49.44.png](https://support.nepton.com/hc/article_attachments/32057460999965)
If person has rights to edit compensation type default or vacation days earning, it can be done when adding or editing the event. Work time role rights can be managed in the Worktime Roles - Worktime roles permissions menu.
