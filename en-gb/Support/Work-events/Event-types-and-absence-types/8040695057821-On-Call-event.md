# On Call event

On some industries it may be necessary that after official working hours employee will be on On Call/”Standby” and will return to work for example when emergency situations occur. On Call time is possible to mark on Nepton.
![](https://support.nepton.com/hc/article_attachments/20138567884189)
On Call event is added to Nepton the same way as normal Work, Annual leave etc. On Call is different than most of the other event types because you can add other events at the same time.
## Event type
To be able to use On Call event type it needs to be set visible. You can edit the visibility on Working Community or Setting group level (Work hours > Event types)
You can find more info about event types [here](<https://support.nepton.com/hc/en-gb/articles/360002520778-Event-types>).
## On Call settings
On Call settings can be found in **Working Community** or **Setting group** level **Work hours > On Call**
![](https://support.nepton.com/hc/article_attachments/20138590790685)
### Show breakdown for On Call hours
This setting tells if the On Call hours are shown in the calendar. If no setting has been defined, the calculated hours for the recorded On Call event are shown. The amount shows On call hours which might have been reduced by overlapping events, depending on the settings. This setting does not support exceptions: you can only choose to always show the breakdown or to always hide it from the calendar view. 
![](https://support.nepton.com/hc/article_attachments/20138567889309)
### Event types overriding On Call time
When calculating On Call hours, Nepton reduces some type of events from On Call hours, if they are recorded at the same time. As a default this is valid for all the event types but it can be changed by settings.
For example, if it should be possible to earn normal working hours and On Call hours at the same time, you can make a customized event type for 'working while On Call', and change the regular Work event type the way that it won’t be reduced from On Call.
Note! This feature was added to Nepton on update 2.12.0 (13.05.2023) ‘Show breakdown for all on call hours’ were set “NO” for all the customers. This can be changed as “Yes”, but if customer has integration where On Call hours are transferred in salary integration, customer needs to assure, that the rule set is updated also. More information [here](<https://support.nepton.com/hc/en-gb/articles/8405862536349-Deprecated-ruleset-examples>).
