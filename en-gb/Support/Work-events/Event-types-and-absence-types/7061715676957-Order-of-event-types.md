# Order of event types

There is a setting at working community level, where you can specify the order in which you want to display selectable event types when creating an event. The order can be determined to be different in terminals and mobile view than when adding an event in the work time calendar. Events can be dragged to a place where they should appear on the list when adding an event.
Setting can be found in **Worktime > Administration > Working community settings > Work hours > Event type sorting.**
