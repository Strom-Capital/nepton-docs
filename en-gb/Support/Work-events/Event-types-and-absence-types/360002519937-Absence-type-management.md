# Absence type management

Nepton has dozens of different event types as standard. One of these is Absence, under which absence types can be defined. When absence types have been set for the Absence event type, they will appear in the list when adding a new Absence event. It is not possible to select the absence type when recording events via terminal, the absence type is always "Other" by default. Whether an absence type is paid and whether it accumulates annual leave can be determined in the settings
Absence types are managed in **Worktime > Administration > Setting groups/Working community settings > Work hours > Absence types.** ![](https://support.nepton.com/hc/article_attachments/32929827291037)
The following setting is used as the default for the absence type, unless otherwise specified:  

**Absence type**  
| **Paid** | **Accrues annual leave**  
---|---|---

Family member becoming sick suddenly | No | Yes  
Family members death | Yes | Yes  
Family members funeral | Yes | Yes  
Leave of absence | No | No  
Maternity leave | Yes | Yes  
Military call to arms happening | Yes | Yes  
Military or civil service time | No | No  
Military refresher course | Yes | Yes  
Moving leave | Yes | Yes  
Nursing leave | No | No  
Off duty | No | No  
Other | No | No  
Own 50th or 60th birthday | Yes | Yes  
Own marriage | Yes | Yes  
Parental leave | No | Yes  
Parental leave (pre-reform) | No | Yes  
Part time pension | No | No  
Part-timer | No | No  
Paternity leave | Yes | Yes  
Personal request leave | No | No  
Pregnancy leave | Yes | Yes  
Rehabilitation | Yes | Yes  
Sabbatical leave | No | No  
Special maternity leave | Yes | Yes  
Study leave | No | Yes  
Temporary nursing leave | Yes | Yes  
Trade union events | Yes | Yes  
Whether the absence type is paid and accumulates annual leave can be modified when adding new event, if the person has the right to approve events. This setting is done in the **Worktime > Administration > Worktime roles > Work time permissions menu**. If you want the person to be able to specify the type of absence compensation when creating the event, select Can approve personal events under Medium-level permissions. If you want the person to be able to specify the type of absence compensation when creating an event for their subordinates, select Can edit and approve subordinates entries under Medium-level permissions. If you do not want the person to have these rights, unselect them.
All absence types are shown in work shift planning calendar as "Absence" without any further details.
