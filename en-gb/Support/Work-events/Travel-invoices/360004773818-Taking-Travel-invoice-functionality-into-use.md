# Taking Travel invoice functionality into use

Travel invoice functionality is included in the **Complete service level**.
Travel compensations with possible attachments can be recorded on travel invoices. The service automatically calculates the daily allowances and suggests the number of kilometers based on the route.
Travel invoices are enabled as follows:
  1. Set the travel invoice event type to be selectable either in the working community settings or for the setting groups where travel invoices are to be used. The visibility of the travel invoice can also be set individually in person settings. Instructions for managing visible event types can be found [here](<https://support.nepton.com/hc/en-gb/articles/360002519157>).
  2. Set the rules for automatic filling of daily allowances for travel invoices. Instructions for setting the rules can be found [here](<https://support.nepton.com/hc/en-gb/articles/360002559777>).
  3. Set work supplements by using names that are used as travel invoice expense lines, route allowances, or daily allowances. The titles are freely definable. You can also use a pre-defined translation tag in the supplement name. These translation tags present the most common expenses in travel invoices. These translation tags are listed at the end of this guide article.  
Instructions for setting up the supplements can be found [here](<https://support.nepton.com/hc/en-gb/articles/360002559637>).


In order for a supplement to be selectable for travel invoices, it must be specified that it is used for travel invoices. The supplement can either be reimbursement of the route (kilometer allowance), reimbursement of the travel day (daily allowances and meals) or reimbursement of other expenses (for example a hotel).![](https://support.nepton.com/hc/article_attachments/33718936078237)
If the supplement used is Travel day allowances, also select the correct type of compensation (calculated as).![](https://support.nepton.com/hc/article_attachments/33718945869597)
If the supplement is an allowance or other type that has decimals in its value, select the unit type of the supplement as "Decimals".  
  
![](https://support.nepton.com/hc/article_attachments/33718936081565)
The pre-defined translation tags to be used in travel invoice supplements are listed below. The translation tag is set as the name of the supplement. The benefit of these translation tags compared to “normal” supplement names is that they respect the language selection in Nepton.
daily_allowance  
partial_daily_allowance  
foreign_daily_allowance  
paid_lunches  
meal_reimbursement  
other_expenses  
telephone_expenses  
car_(alone)  
car_(1_passenger)  
car_(2_passengers)  
car_(3_passengers)  
car_(4_passengers)  
motorbike
  
After defining the supplements, the travel invoices are ready to be used. Instructions for adding a travel invoice can be found [here ](<https://support.nepton.com/hc/en-gb/articles/360004788238>)and instructions for approving travel invoices can be found [here](<https://support.nepton.com/hc/en-gb/articles/360005381337>).
