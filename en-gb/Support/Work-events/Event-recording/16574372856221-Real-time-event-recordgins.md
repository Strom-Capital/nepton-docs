# Real-time event recordgins

Events can be recorded in Nepton in real-time or before/after the time of the event. Events recorded in real-time are distinguished from events recorded in advance and afterwards by the Building and Clock icons. The icons are displayed in connection with the event in the Events in calendar view and in the approval of events.
If the real-time recording has been done with a Nepton Touch or Nepton Flexim work time terminal, this is indicated by the Building icon. If the real-time recording has been done on another device (e.g. a mobile phone, via a browser or with a Nepton Rugger work time terminal), the Clock icon is displayed.
If the event has not been recorded in real-time, the icons will not be displayed regardless of the device on which the recording was made. Accepting the event or editing the data (excluding the time) does not affect whether the event is interpreted as real-time. If the time of a real-time recorded event is changed afterwards, the recording is no longer real-time and icons are not displayed in connection with it.
## Event recorded in real-time with a terminal
If an event is recorded in real-time with a terminal, the event will have a Building icon next to it, such as in the image below:
![](https://support.nepton.com/hc/article_attachments/16574746111773)
By clicking the event more information is displayed such as description that the event is recorded in real-time with a terminal.  
![](https://support.nepton.com/hc/article_attachments/16574746122397)
## Event recorded in real-time with other device than terminal
If an event is recorded in real-time with some other device than a terminal, a Clock icon will be displayed next to the event, such as in the image below:
![](https://support.nepton.com/hc/article_attachments/16574746134685)
By clicking the event more information is displayed, such as description that the event is recorded in real-time.
![](https://support.nepton.com/hc/article_attachments/34907298021277)
There must be at least 1 minute between events recorded in real time, in order for them to be interpreted as separate events.
