# Calendar view presentation

The calendar view can be found in the menu **Worktime > Work hours > Events in calendar**. The Events in calendar view always shows the current calendar month and the logged-in user's calendar by default.
![](https://support.nepton.com/hc/article_attachments/33208374259869)
By clicking on the date row, you can change the view's time period to the desired time period, either by selecting the days manually or moving forward/backward by using the arrow buttons.
![](https://support.nepton.com/hc/article_attachments/33208374260765)
In the example below, only one day, January 5, 2026, has been selected as the view using the date search function.
## Day's basic information
![](https://support.nepton.com/hc/article_attachments/33208374261149)
**The Week** row shows the week number, year and date. By clicking on the date you can[ add a new event](<https://support.nepton.com/hc/en-gb/articles/360002596797>) to the day. The Total column shows the total data per week for the period searched in the calendar view.
**The Events** row shows all[ event types](<https://support.nepton.com/hc/en-gb/articles/360002520778>) recorded for the day. In the example, the added event "Work" is marked for the time period 08:00-17:30. This event is assigned to the project "Varasto (warehouse)". The event includes an automatically generated[ lunch break](<https://support.nepton.com/hc/en-gb/articles/360002558757>) from 11:30-12:00. In addition, there is another work event during the day from 19:00-20:00.
**Worked time incl. absences** indicates the recorded working time after deducting unpaid time. In this example, the lunch break of 30 mins has been subtracted from worked time including absences value. If roundings are in use, any time created due to rounding up is not shown on this row. NOTE: Accrual leaves are not shown on this line, even though they are paid absences.
In the example, **regular time is** filled by the Work event. Regular working hours are filled when work has been done for the [length of the working day](<https://support.nepton.com/hc/en-gb/articles/360002558417>), i.e. in this case 07:30 hours. Regular working hours could also be filled from an [accrual](<https://support.nepton.com/hc/en-gb/articles/360005073918>), if the work obligation isn't fulfilled. Any hours targeted "hour to hour to salary" are also shown on this line.
**The Overtime** row appears in the calendar if overtime has been earned during the week. The [overtime portion of an event](<https://support.nepton.com/hc/en-gb/articles/360002481617>) can be handled in many different ways, depending on what is defined in the [settings](<https://support.nepton.com/hc/en-gb/articles/4417295059985>). In this example, the time exceeding regular working hours of the event is allocated with Overtime - Salary target. The portion exceeding regular working hours, 02:30, is overtime. Under the Overtime heading, you can see that it has been allocated to salary. By clicking on the triangle next to it, you can open an even more detailed breakdown of overtime:
![](https://support.nepton.com/hc/article_attachments/33208358067997)
After overtime, **supplements** are shown, if any have been recorded. [Supplements ](<https://support.nepton.com/hc/en-gb/articles/360002559637>)are one-time compensations that are added manually. In the example, the supplement Asuntonäyttö ilta has been added to the event once.
Next any automatically generated increments, i.e. [work rises](<https://support.nepton.com/hc/en-gb/articles/360002560978>), are shown. In the example image, 1 hour of evening increment (iltalisä) has been generated. Work rises can be accrued based on the time of day, event type, and event type compensation type.
The bottom row shows all displayed **accruals** in use. In the example, the accrual types used are balance, bank, holiday pay, kausiainsainta, testikertymäl, weekly rest and work time shortening leave. If there is an event on the day that affects the accrual, the negative or positive balance for the accrual on the day is displayed.
## Worktime calculation criteria
Clicking on the date in the calendar view opens the view below, worktime calculation criteria. The view tells you the settings the interpretation of the work day is based on.
![](https://support.nepton.com/hc/article_attachments/33208941320093)  
  
The [work day obligation](<https://support.nepton.com/hc/en-gb/articles/360002558417>) in the example is defined in the settings as 7 hours and 30 minutes, meaning the person's regular working hours are 7 hours and 30 minutes per day.
The[ work week obligation](<https://support.nepton.com/hc/en-gb/articles/360002558537>) in the example is defined as 37 hours 30 minutes, meaning the person's regular weekly working hours are 37 hours 30 minutes.
[Expected working hours](<https://support.nepton.com/hc/en-gb/articles/360002558617>) affect the interpretation of overtime. Using expected working hours can enable overtime to be earned even before the actual work shift or established working hours. In this example, the expected working hours are 00-24:00.
[Permitted working hours](<https://support.nepton.com/hc/en-gb/articles/360002558597>) define the hours outside of which work performed is not considered working time. In this example, the permitted working hours are 06:00-20:00. If the Work event in the example had been started before 06:00, the time before 06:00 would not have been considered working time. If the Work event in the example had been finished after 20:00, the time after 20:00 would not have been considered working time.
## Event's basic information
By clicking on a registered event in the calendar, more detailed information about that event will open in a new window.
![](https://support.nepton.com/hc/article_attachments/33208941323165)
The information displayed about the event includes the total duration of the event, overtime earned from the event, recorded supplement, and the event creator.
[The Event edit history](<https://support.nepton.com/hc/en-gb/articles/360002521298>) feature allows you to view the original entry of the event and other older versions if it has been edited since creation.
[The Event listing report](<https://support.nepton.com/hc/en-gb/articles/360002548877>) shows all recorded and deleted events.
[The Copy event ](<https://support.nepton.com/hc/en-gb/articles/360002521078>)function allows you to copy an event to multiple times and people.
[The Related Events](<https://support.nepton.com/hc/en-gb/articles/360002521118>) function allows you to mass delete copied events from the calendar view as long as the events have not been edited or approved.
The event can be [deleted](<https://support.nepton.com/hc/en-gb/articles/360002520978>).
Events for the period searched for in the calendar view can be [approved ](<https://support.nepton.com/hc/en-gb/articles/360002519197>)directly from the calendar at the end of the week or for the entire calendar view. The right to approve events depends on the rights granted by the [worktime roles](<https://support.nepton.com/hc/en-gb/articles/360002554338>).
## Summary
  
At the bottom of the calendar view is a summary of the hours in the entire view. Below is an example of a summary of an entire month.
![](https://support.nepton.com/hc/article_attachments/33208957549981)
In addition to the information displayed in the calendar view, the summary shows the event types used, the number of public holidays, annual leave days used, and public holiday compensation.
