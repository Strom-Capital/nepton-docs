# Projects API

This article describes the Work Time API methods for handling projects. Read more about how to implement API [here](<https://support.nepton.com/hc/en-gb/articles/360004861518>).
## Get projects
With API it is possible to search for projects and locations and filter the results.
API methods for searching for projects:
  * [GetProjects (obsolete)](<https://support.nepton.com/hc/fi/articles/6913429557405>)
  * [GetProjectsV2](<https://support.nepton.com/hc/fi/articles/6904062030621>)


## Adding and updating projects
The service allows you to add and update projects. The service provides methods for adding a project, updating a project, and a third option that allows you to either create or update projects in Nepton based on some identifier with a single call. The latter option is designed specifically for batch runs and data synchronization between Nepton and a separate system.
API methods for adding projects:
  * [InsertProjects](<https://support.nepton.com/hc/fi/articles/6903131386013>)


API methods for updating projects:
  * [UpdateProjects](<https://support.nepton.com/hc/fi/articles/6913613074845>)


API methods for creating new or updating existing projects: 
  * [EnsureProjectsExist (obsolete)](<https://support.nepton.com/hc/articles/6880677487005>)
  * [EnsureProjectsExistV2 (obsolete)](<https://support.nepton.com/hc/articles/360005783318>)
  * [EnsureProjectsExistV3](<https://support.nepton.com/hc/en-gb/articles/13106403486109>)


## Changing project visibility at user level
The service allows you to change the visibility of projects at a user level.
API methods for making projects visible for a user:
  * [SetVisibleProjectsForUser (obsolete)](<https://support.nepton.com/hc/fi/articles/6885147716893>)
  * [SetVisibleProjectsForUserV2](<https://support.nepton.com/hc/fi/articles/360005968797>)


API methods for clearing project visibility for a user:
  * ClearVisibleProjectsFromUser
