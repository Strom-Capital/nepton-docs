# Worktime Integrations API

This article describes Work Time API methods for handling worktime integrations.
## Retrieving the integration file
It is possible to run a rule set added to NeptOn and obtain its data in the desired format (for example CGI Salaries data).
API methods:
  * [RunIntegrationRuleSet (obsolete)](<https://support.nepton.com/hc/fi/articles/6881855535773>)
  * [RunIntegrationRuleSetV2](<https://support.nepton.com/hc/fi/articles/360014449458>)
