# Events API

This article describes the Work Time API methods for handling events. [This article](<https://support.nepton.com/hc/en-gb/articles/360004861518>) describes how to implement the API.
## Get activities
API can be used to retrieve work events, absences, vacation days, travel expenses, planned shifts, and other event information. The retrieved data can also be filtered using specific criteria (e.g. user or time period)
API methods for retrieving events
  * [GetActivities (Obsolete)](<https://support.nepton.com/hc/fi/articles/6580727241501>)
  * [GetActivitiesV2 (Obsolete)](<https://support.nepton.com/hc/fi/articles/6580610511133>)
  * [GetActivitiesV3](<https://support.nepton.com/hc/fi/articles/360020751677>)


Insert activities
Through API you can add events, absences, vacation days, travel expenses or other event information for a user.
API methods for adding events:
  * [InsertActivities (obsolete)](<https://support.nepton.com/hc/fi/articles/6788254740893>)
  * [InsertActivitiesV2 (obsolete)](<https://support.nepton.com/hc/fi/articles/6788513921565>)
  * [InsertActivitiesV3](<https://support.nepton.com/hc/fi/articles/6788985086621>)


## Update activities
You can update defined events via API. In addition to the unique Nepton identifier, it is possible to indicate the events to be updated with an external identifier, if one has been defined for the event during the addition phase.
API methods for updating events:
  * [UpdateActivities (obsolete)](<https://support.nepton.com/hc/fi/articles/6865125183261>)
  * [UpdateActivitiesV2 (obsolete)](<https://support.nepton.com/hc/fi/articles/6865441448861>)
  * [UpdateActivitiesV3](<https://support.nepton.com/hc/fi/articles/6865760767645>)


## Get activity types
You can search for all event types defined in Nepton, as well as event type names in all languages ​​supported by Nepton.
API methods for searching for event types:
  * [GetActivityTypes](<https://support.nepton.com/hc/articles/6899092915101>)


Depending on your settings, some event types may not be available to all users. To retrieve event types that are appropriate for a specific user, see the [Terminal Services API](<https://support.nepton.com/hc/en-gb/articles/360019841037>) web service method.
