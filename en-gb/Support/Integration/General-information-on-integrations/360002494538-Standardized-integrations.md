# Standardized integrations

The services below have a technical interface implementation. The files of standardized interfaces can also be used in other services, provided they support the file format in question.
You can find a detailed description of each interface in the Support pages by using the system name as a keyword or by following the links in the list below. In the update made to Nepton on May 13, 2023, some interface names were changed to their current official form. The previous name used in Nepton appears in parentheses after the new name.
More information about integrating interfaces can be obtained from your vendor.
