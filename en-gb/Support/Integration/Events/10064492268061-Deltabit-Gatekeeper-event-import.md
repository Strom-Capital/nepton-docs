# Deltabit Gatekeeper event import

Events from the Deltabit Gatekeeper system can be imported into the service. Deltabit Gatekeeper uses Nepton's standardized application interface (API) to import events. The method used is InsertActivities, which you can read more about [here](<https://support.nepton.com/hc/en-gb/articles/6788254740893>). Events are imported daily at 03:00.
