# Removing events created with integration, file import or by copying

In this article, events imported via file refer to events that have been imported using the _Tools > Import events _functionality.  
Events imported or copied via file can be deleted in bulk if the data is incorrect or the same data has been imported multiple times. Deletion is carried out using the **Related events** function or by selecting the events you wish to delete.
1\. Navigate to **Worktime > Work hours > Events in calendar.**
![](https://support.nepton.com/hc/article_attachments/34350069202973)
2\. Select the event you wish to delete.
3\. Select **Related events** , which will display the events that were created at the same time as the selected event. With the top checkbox (next to the Event ID field), you can select all events at once. The name of the import file is also displayed if the events were imported via _Tools > Import event data_.
![](https://support.nepton.com/hc/article_attachments/34350069203613)
4\. **Delete events** deletes the selected events.
