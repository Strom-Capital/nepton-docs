# Person Export

The person export features allow you to export HR data from Nepton to an external system.
HR data can be exported using two different methods:
  1. **Manual export** : Most HR data fields can be exported to an Excel file. See details on [Export person data to Excel](<https://support.nepton.com/hc/articles/360002430478>) page.  
  

  2. **Scheduled export** : HR data can be scheduled to be exported on a regular basis. See details on [Scheduled task - person export](<https://support.nepton.com/hc/articles/360002489357>) page.
