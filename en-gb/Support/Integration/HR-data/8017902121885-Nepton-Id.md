# Nepton Id

Nepton Id is a unique field used by Nepton to identify person especially in integrations. It is a value that will not change for a person in Nepton. Nepton Id is visible on person form and available as a value identifying the person in [default person import](<https://support.nepton.com/hc/articles/360003762577>) and [person export in JSON format](<https://support.nepton.com/hc/articles/7982660700189>). Technically, Nepton Id is a [Universally unique identifier](<https://en.wikipedia.org/wiki/Universally_unique_identifier>) represented as a string consisting of 32 hexadecimal digits separated by four hyphens: 8 digits - 4 digits - 4-digits - 4 digits - 12 digits. The code may be in upper or lower case; however, Nepton displays the code in upper case in person form and in the person export.
Example:
4980D074-36F8-5627-9F08-0F05F4642EDA
