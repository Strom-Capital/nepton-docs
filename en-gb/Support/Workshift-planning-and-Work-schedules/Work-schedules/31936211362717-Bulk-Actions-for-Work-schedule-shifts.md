# Bulk Actions for Work schedule shifts

This instruction describes the use of bulk actions in planning view. Bulk actions are designed to make planning easier in situations where multiple shifts need to be managed simultaneously. With bulk actions, you can edit the details of several shifts, copy shifts, move shifts, or delete shifts all at once. Bulk actions are used in the planning view of shift scheduling. This instruction covers bulk actions for work schedule shifts. The use of bulk actions in detailed planning is described in a separate [article](<https://support.nepton.com/hc/en-gb/articles/8271501506973-Bulk-actions>).
### Selecting shifts
When using bulk actions, shifts are first selected in the planning view. Start by clicking **Bulk Actions** and choose the shifts you want to edit.
![Screenshot 2025-12-02 120550.png](https://support.nepton.com/hc/article_attachments/32233367337629)
Shifts can be selected by clicking:
  * A single shift
  * A day cell
  * A week cell
  * A location cell at the location row
  * A resource cell at the person row
  * Select All function, additional options open from the downward arrow button


Once the shifts have been selected, continue by choosing the desired action.
![Screenshot 2025-12-02 120757.png](https://support.nepton.com/hc/article_attachments/32233398802333)
### Edit action
The Edit action allows you to modify the details of selected shifts in the planning view. The following details can be changed during editing:
  * Event type: The event type of a custom shift
  * Shift type: The event type of a calendar shift
  * Shift details / Note: A note to add or remove from the shift
  * Planner details: Custom shift information visible in the planning view
  * Shift abbreviation: Abbreviation for the custom shift
  * Start and end date and time: The timing of the shift can be changed
  * Task: Tasks to add to the shift
  * Person: The person to assign to the edited shift, to whom the selected shifts will be moved


When all editing selections have been made, click **Edit** at the bottom of the view.
![Screenshot 2025-12-02 120952.png](https://support.nepton.com/hc/article_attachments/32233398802973)
### Copy action
The Copy action allows you to duplicate selected shifts in the planning view. When copying, you must set the repetition and time interval. In addition, the following details can be modified:
  * Event type: The event type of a custom shift
  * Shift type: The event type of a work schedule shift
  * Shift information / Note: A note to add or remove from the shift
  * Shift information for planners: Shift information visible in the planning view
  * Shift alias: Alias for the custom shift
  * Task: Tasks to add to the shift
  * Location: The location of the custom shift (cannot be changed for work schedule shifts)
  * Person: The person to assign to the copied shift. If a person is added, the copied shifts will be moved to that person
  * Additional options


When all copy settings have been made, click **Copy** at the bottom of the view.
![Screenshot 2025-12-02 121245.png](https://support.nepton.com/hc/article_attachments/32233398804893)
### Move action
The Move action allows you to move selected shifts in the planning view. The following details can be changed during the move:
  * Date: The new date to which the shifts will be moved
  * Person: The person to assign to the moved shift. If a person is added, the selected shifts will be moved to that person


Shifts cannot be moved to another work schedule. When all move selections have been made, click **Move** at the bottom of the view.
![Screenshot 2025-12-02 121659.png](https://support.nepton.com/hc/article_attachments/32233367345437)
### Delete action
The Delete action allows you to remove selected shifts in the planning view. Before deleting, you will see a summary of the shifts to be removed. It is important to note that deletion is permanent and cannot be undone.
![Screenshot 2025-12-02 121855.png](https://support.nepton.com/hc/article_attachments/32233367348125)
