# Rolling work shift view

It is possible to display the current day's shifts on the screen so that the list on the screen is updated automatically.
From the working time settings for shift planning, you can select how the information is to be displayed on the screen. The settings can be found: Worktime > Administration > Working Community Settings > Work Shifts. Select the correct person group(s), as well as the refresh interval and the order of information presented.
![mceclip0.png](https://support.nepton.com/hc/article_attachments/4404363971473/mceclip0.png)
Click ”Create url for rolling workshift view” and a web address is created in the field below. By opening this web address on any terminal, the rolling workshit view can be shown with up-to-date content.
The content presents the current day's shifts and the planning level, task and public comment assigned for the shift. In addition, notifications that are visible to everyone can be displayed at the bottom of the screen, ie notifications that have been set visible to "All Users" in the "Visibility of notification” settings. Notifications are created in the communication section of the service, so that must be switched on at the working community level (Work time > Administration > Working community settings > Communication) in order to display notifications in the scrolling view.
