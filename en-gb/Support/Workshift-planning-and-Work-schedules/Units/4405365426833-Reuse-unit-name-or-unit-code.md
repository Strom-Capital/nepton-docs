# Reuse unit name or unit code

### Reuse unit name:
Unit name is unique and can’t be used more then one time. To be able to re-use the unit name again, you should rename the unit that has the same name.
### Reuse unit code:
Unit code is unique and can’t be used more than one time. To be able to re-use the unit code again, you should update the code of the unit that has the same code.
### Rename unit or update code:
Go to **Employees > Units**. You'll receive a list of units with an edit icon (magnifying glass) next to them.
![](https://support.nepton.com/hc/article_attachments/28219758675101)
Update the unit's name and code in the unit's information and save the information. NOTE: make sure that the deleted units do not have the same name or code. First delete/change the information from the deleted unit, and only then add it to the active unit, so that there are no duplicate names or codes in the service.
![](https://support.nepton.com/hc/article_attachments/28219758683805)
_**To update a deleted unit you should restore the unit first**_ \- see [Restoring a removed unit](<https://support.nepton.com/hc/en-gb/articles/4407415340561>).
