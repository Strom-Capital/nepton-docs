# Shift Planning rest-time rules

Nepton helps shift planners to comply with TES rest-time rules. TES rest-time rules ensures healthy work time routine for employees. Nepton facilitates shift planners to see visually if any of these rules are violated. What are these rules, how to set these and how it helps planning are all described below:
These rules can be enabled under the following section **Employees > Administration > Settings > Planning**
## Per day rules
  * **Maximum daily planned hour:** the maximum amount of consecutive hours a person can work in one day. Save a value in format hours:minutes e.g. 13:30 (13 hours and 30 minutes)
  * **Minimum daily rest time:** the amount of mandatory rest time per day (calendar day) for a person. Save a value in format hours:minutes e.g. 7:00 (7 hours)


## One week rules
  * **Minimum weekly rest time:** the amount of mandatory rest time in one week period for a person. Save a value in format hours:minutes e.g. 10:30 (10 hours and 30 minutes)
  * **Maximum consecutive workdays in a week:** the amount of maximum consecutive workdays for a person in one week period. Save a value in numeric format e.g. 5 (5 days)


## Two consecutive weeks rules
  * **Maximum consecutive workdays in two weeks:** the amount of maximum consecutive workdays for a person in two weeks period. Save a value in numeric format e.g. 10 (10 days)


When these value are set then shift planner will get warning messages in fine planning if any of these rules are violated. Examples of these warning messages are as following:
