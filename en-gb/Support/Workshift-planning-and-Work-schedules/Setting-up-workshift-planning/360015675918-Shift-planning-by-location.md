# Shift planning by location

You can define the following information for the shift planning location:
  * Planning shifts templates
  * Planning settings
  * Planning persons


![mceclip0.png](https://support.nepton.com/hc/article_attachments/7293811119005)
### Location templates:
Activity templates allow you to speed up the distribution of regular shifts. You can create a need shift for the location base . Instructions for creating a shift plan [here.](<https://support.nepton.com/hc/fi/articles/360010082738>)
![mceclip1.png](https://support.nepton.com/hc/article_attachments/7293975752989)
### Location settings:
Use the Location settings to define default settings such as start time and end time, color of the planning level, reduction of the assumed lunch break.
![mceclip2.png](https://support.nepton.com/hc/article_attachments/7294174433821)
### Location Persons
You can add / remove persons from location via the Location Persons settings.
![mceclip3.png](https://support.nepton.com/hc/article_attachments/7294673537181)
