# Direct login links for SAML SSO and Microsoft login

If you use a SSO (single sign on) login to the service, then the login can be made easier by using the direct login link.
You can save the link to your browser as a bookmark or as a shortcut on your desktop.
Instructions for creating a SAML SSO direct sign-in link can be found [here](<https://support.nepton.com/hc/en-gb/articles/360002590097>).
Instructions for creating an Microsoft login direct login link can be found [here](<https://support.nepton.com/hc/en-gb/articles/360002590137>).
