# Login to Nepton

This page introduces all the different ways you can log in to the service. A separate article can be found for [logging in with a mobile device](<https://support.nepton.com/hc/en-gb/articles/360002602598>). Web addresses and agreed policies may vary by organization. If necessary, verify your own policies with your organization administrator.
Guidance to most common problem situations can be found [here](<https://support.nepton.com/hc/en-gb/articles/21229494759069>).
If you are using the service for the first time, you can set your password by clicking on the 'Forgot password' link. After entering your email address, you will receive further instructions via e-mail.
## Login with username and password
1\. Enter <https://go.nepton.com/> in the address bar of your browser. The same address is used when using a mobile device. Separate instructions for logging in on a mobile device can be found [here](<https://support.nepton.com/hc/en-gb/articles/360002602598-Login-to-Nepton-mobile>).
2\. The first time you log in, enter the name of your working community and press the **Search** button. You can also find a working community by typing part of the name and pressing Search. The selection remains in the browser cache and no longer needs to be entered unless the web browser cache is cleared.
![](https://support.nepton.com/hc/article_attachments/29558061452573)
3\. In the login window that opens, all the login methods that have been enabled in the working community will be displayed. Options can be Nepton credentials, Single Sign-on methods and RFID tag. To login with Nepton credentials, enter your username and password and press the **Sign in** button.
![](https://support.nepton.com/hc/article_attachments/29558044856989)
4\. If the working community needs to be changed, it can be re-selected by pressing the working community name in the upper left corner.
5\. If different login methods are enabled for the working community, the method can be changed by pressing **Other options**.
If login credentials are given incorrectly too many times, the credentials will be locked for five minutes. You will receive a notification about this. Login can be tried again after five minutes.
Logging in with [Nepton credentials can be prevented](<https://support.nepton.com/hc/en-gb/articles/13194036455325>).
## Single sign-on 
It is possible to log in to the service using single sign-on. Different single sign-on methods are described [here](<https://support.nepton.com/hc/en-gb/articles/360011143457>). The following example is made using Microsoft single sign-on.
Login with Nepton username/email and password can be [removed from list of allowed login methods](<https://support.nepton.com/hc/en-gb/articles/13194036455325>). 
1\. Enter <https://go.nepton.com/> in the address bar of your browser.  
2\. The first time you log in, enter the name of your working community and press the **Search** button. You can also find a working community by typing part of the name and pressing Search. The selection remains in the browser cache and no longer needs to be entered unless the web browser cache is cleared.
![](https://support.nepton.com/hc/article_attachments/29558044857629)
3\. In the login window that opens, all the login methods that have been enabled in the working community will be displayed. Options can be Nepton credentials, Single Sign-on methods and RFID tag. In the login view that opens, press the Microsoft login button.
![](https://support.nepton.com/hc/article_attachments/29558061460509)
4\. If the working community needs to be changed, it can be re-selected by pressing the working community name in the upper left corner.
5\. If different login methods are enabled for the working community, the method can be changed by pressing **Other options**.
## Logging in with RFID tag
It is possible to log in using RFID tag. Instructions on how to enable this possibility can be found [here](<https://support.nepton.com/hc/en-gb/articles/13194906030365>).
1\. Enter <https://go.nepton.com/> in the address bar of your browser.  
2\. The first time you log in, enter the name of your working community and press the **Search** button. You can also find a working community by typing part of the name and pressing Search. The selection remains in the browser cache and no longer needs to be entered unless the web browser cache is cleared.
![](https://support.nepton.com/hc/article_attachments/29558044859549)
3\. In the login window that opens, all the login methods that have been enabled in the working community will be displayed. Options can be Nepton credentials, Single Sign-on methods and RFID tag.
![](https://support.nepton.com/hc/article_attachments/29558044861725)
4\. When using RFID-login, a separate RFID reader needs to be attached to the computer.
![](https://support.nepton.com/hc/article_attachments/29558061465629)
After the RFID-tag has been read, you will need to authenticate yourself by giving your PIN code.
![](https://support.nepton.com/hc/article_attachments/29558044868893)
After giving your PIN code, press **Sign in** and you will be directed to the service.
## Logging in to the recording terminal with an RFID tag
1\. The personal identifier is shown to the reader. Set your RFID tag on the reader and wait for a sound signal.
![mceclip0.png](https://support.nepton.com/hc/article_attachments/4406926987409)
2\. Then select the desired function and save the selection from the **Start** button at the bottom of the screen.
![mceclip1.png](https://support.nepton.com/hc/article_attachments/4406927029649)
## Logging in to the recording terminal with a PIN number
1\. The personal PIN number is entered using the keypad on the terminal and the **Login** button is pressed. 
![mceclip0.png](https://support.nepton.com/hc/article_attachments/4406926987409)
2\. Then select the desired function and save the selection from the **Start** button at the bottom of the screen.
![mceclip1.png](https://support.nepton.com/hc/article_attachments/4406927029649)
