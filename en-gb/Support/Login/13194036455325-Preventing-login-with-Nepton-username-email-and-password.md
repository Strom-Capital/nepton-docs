# Preventing login with Nepton username/email and password

Login to Nepton can be restricted, for example in a situation where you want to allow login only using single login. The advantage of this is that login to Nepton can be managed through single login as a whole.
By blocking logging in with Nepton credentials:
  * Nepton credentials can't be used for logging in anymore
  * Nepton users can't set or reset password for themselves anymore
  * [Administrators](<https://support.nepton.com/hc/en-gb/articles/360002425637-Roles>) can still set password for users in Person's [Additional Functions](<https://support.nepton.com/hc/en-gb/articles/360002430418-Setting-a-new-password-for-another-user-by-admin>) page  

    * The authentication of the application interfaces still works with Nepton's username/email and password


In order to prevent logging in with Nepton username and password, do the following:
  1. Go to **Employees > Administration > Settings > Login**.
  2. Untick the box for "Allow login with Nepton username/email and password"
  3. Press **Save**.
