# Travel Invoices in Reporting

# Basic Principles
From travel expense reports, the following information can be added to a query:
  * Trip start and end dates
  * Travel allowances recorded on the expense report (e.g., Car: solo)


## Available Fields
  * Travel mode identifier (car, airplane, ship, public transport, other)
  * Trip departure date and time
  * Trip departure timezone
  * Trip arrival date and time
  * Trip arrival timezone
  * Departure address and country
  * Destination address and country
  * Trip purpose
  * Whether the travel report is approved
  * Travel report approver


## Can not be added to a query
  * Foreign travel allowance details (which country’s rate applies)
