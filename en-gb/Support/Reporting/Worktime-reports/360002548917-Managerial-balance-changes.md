# Managerial balance changes

Balance changes can be monitored with a separate report, which can be found in the **Worktime** section under **Work hours > Reports**.
You can find more information about managing balance [here](<https://support.nepton.com/hc/en-gb/articles/360002485598-Setting-and-changing-accrual-values>).
![](https://support.nepton.com/hc/article_attachments/26983239453597)
The managerial balance changes report shows the balance changes during the reporting period by user per day. The events shown in the report include:
\- Limiting the balance: The balance has reached the set maximum or minimum amount.  
\- Balance setting: A Balance reset has been made for the user in the calendar, which has set the balance to a certain value.  
\- Change of balance: A Balance change event has been made for the user in the calendar, which has either reduced or added to the balance.
The report can be printed or exported to Excel. In Excel, the balance is shown in decimal format so that the hours can be summed.
Information about the amount of the balance can be seen in the report "Hours by salary type", limited to one day. Please note that no balance information has yet been created on the current day, so the day to be reported must be earlier than the current day.
