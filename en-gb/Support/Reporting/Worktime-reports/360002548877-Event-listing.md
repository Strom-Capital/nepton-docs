# Event listing

The event listing reports both saved and deleted events. The report content can be filtered using a keyword. 
The event listing can be found under the menu **Worktime > Work hours > Reports.**
Please note that the event listing reports marked time, not interpreted worktime.
## Report options
In the report options, first enter the time period, then whether to include deleted events in the report or not, and a possible keyword.
### Key words
The keyword searches for the given string in the following data:
  * Event type name
  * Event notes
  * Event start time (can be searched by date in the format dd-mm-yyyy, for example 02-09-2021, or by time in the format hh:mm, for example 08:00)
  * Name of the project linked to the event
  * Code of the project linked to the event
  * Description of the project linked to the event


There can be multiple words separated by spaces in the keyword, in which case all keywords must appear in the search result. You can exclude a keyword from the search result by placing a minus sign in front of the keyword. For example, the search string could be ‘travel time -office’, which will search for events that contain the word ‘travel time’ but do not contain the word ‘office’. If you want to use two different keywords, such as events, you can write them in the form for example Remote Work + Training. This will search for days that have either Remote Work, Remote Work + Training, or only Training.

For example by searching with keywords "travel time" and including deleted events, the following report is generated:  
![](https://support.nepton.com/hc/article_attachments/27310090194973)
The results include 3 rows of travel time events, out of which one is deleted, and also a work event that has a note including the words "travel time".
## Report data
The report data is displayed on the screen. The results can be exported to Excel or printed. The report data can be filtered in Excel by columns, allowing for a detailed examination of the recorded information.
The report columns are;  
Personnel number - Person's personnel number (if set)  
Employee - Person's name  
Person group - Person's Worktime person group (if set)  
Additional reporting info - Additional reporting information that can be added to the person's details in the Employee tab  
Event type - Which event has been recorded  
Record date - For what date the event was recorded for  
Start time - Event start time  
End time - Event end time  
Duration - Marked duration time of the event  
Projects - Any projects that the event is targeted for  
Created by - Who first created the event  
Created - When the event was first created  
Modified - When the event was last modified  
Event approved by - Name of the person who's approved the event  
Event notes - Possible notes left in the event when creating it  
100% - Whether the event is manually set to be 100% overtime  
Deleted - Yes/No whether the event is deleted  
Terminal - Terminal ID if the event was created on a terminal

## Reporting of deleted events
If the option "Include deleted events" is selected, a "Deleted" column will appear in the report, displaying Yes/No. Deleted events are shown in gray font in the report.
![](https://support.nepton.com/hc/article_attachments/27310090198813)
The following information is shown for deleted events:
  * Personnel number
  * Employee (whose calendar the event was originally added to)
  * Person group
  * Additional reporting info
  * Event type used
  * Record date (when the event was originally added)
  * Original start time, end time, and duration
  * Event projects
  * Original creator of the event
  * Original creation time of the event
  * Most recent modification date of the event (deletion time for deleted events)
  * Approver of the event (if the event was approved)
  * Event note (added comment)
  * 100% (whether the event was 100% overtime)
  * Deleted information (no)
  * Work time terminal (Shows only the terminal that started the event, if the event is stopped on another terminal, it will not show on report)


The username/name of the person who deleted the event is not recorded or displayed in the report.
An event can be opened to a new window by clicking on the "event type" information. In this window, a deleted event can be restored back to being active.
