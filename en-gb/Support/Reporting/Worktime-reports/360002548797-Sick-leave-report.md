# Sick leave report

It is possible to monitor marked sick leaves with the following reports:
Sick leaves per person  
Sick leaves per groups
The reports can be found in **Worktime > Work hours > Reports.**
NOTE! Only events recorded with the default Sick Leave event type are shown on the sick leave reports. If there are custom made event types that behave like sick leave in use, they will not be shown on the sick leave reports.
## Sick leaves per person
In the service, marked sick leave days can be reported by person by selecting the report 'Sick leaves per person'. If the option **Is Kela** **report** is selected for the report, the reporting result is a compilation of sick leave periods at individual level. 
The report shows:
  * Number of absences on working days, Kela days and calendar days
  * If it was a child's illness or an accident
  * If it was a paid absence
  * Reason code for absences (if it is marked)
  * A note if added to the event


The report also shows sick leaves that lasted 1-3 days, 4-30 days and more than 30 days in different columns.
![](https://support.nepton.com/hc/article_attachments/25732000703645)
If the **Is Kela report** option is left unselected, the report displays by person on a daily basis for the reporting period. The report does not show absences broken down according to duration, nor a separate field 'Absences in Kela days'.
![](https://support.nepton.com/hc/article_attachments/25732026547997)
## Sick leaves by person group
The report shows marked sick leave by [person groups](<https://support.nepton.com/hc/en-gb/articles/360002553457>). The report can be run for all personnel or it can be filtered by person groups.
The contents of the report is based on the same information that is shown on sick leaves by person Kela report.
The report shows a summary of the sick leaves of the reporting period for the selected group of people. The report shows:
  * the amount of absences on working days, Kela days and calendar days, broken down by whether it was a child's illness or an accident
  * the amount of absences in the selected person group during the reporting period
  * the amount of people in the selected person groups
  * durations of valid employment relationships in calendar days
  * the number of calendar days in the reporting period
  * HTV percentage (percentage of personal work per year. Calculated by dividing the employment days in the report period by the calendar days in the report period.)
  * sick leave percentage (Calculated by dividing the sick leave days in the report period by the calendar days in the report period.)


The report also displays sick leaves that lasted 1-3 days, 4-30 days and more than 30 days in different columns.
