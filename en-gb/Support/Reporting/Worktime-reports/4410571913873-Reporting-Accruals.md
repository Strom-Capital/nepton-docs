# Reporting Accruals

In the service, various [accruals](<https://support.nepton.com/hc/en-gb/articles/360005073918-Implementation-of-Accruals>) (e.g., balance, working time shortening leaves) can be tracked. Accruals can be reported using various reports. This article describes the different possibilities for reporting accruals.
## Reporting Balance
Balance can be reported using [ Managerial balance changes](<https://support.nepton.com/hc/en-gb/articles/360002548917-Balance-event-report>) report.
The total amount of balance at the requested time can be seen in several different reports, such as the [Realized work hours report](<https://support.nepton.com/hc/en-gb/articles/360016836978-Realized-work-hours>)
See also the instruction [how do I check a persons balance on a particular day](<https://support.nepton.com/hc/en-gb/articles/360002575818-How-do-I-check-a-person-s-balance-on-a-particular-day>)
More information about the reports used for balance reporting can be found [in this article](<https://support.nepton.com/hc/en-gb/articles/360002548557-Worktime-reports>)
## Reporting Worktime shortening leave
Worktime shortening leaves can be reported using the [Worktime shortening leave](<https://support.nepton.com/hc/en-gb/articles/360002548777-Work-time-shortening-leave-report>) report.
## Reporting Annual leave
Reporting the amount of annual leave is possible using the [Annual leave ](<https://support.nepton.com/hc/en-gb/articles/360002548717-Annual-leave-reporting-aka-Holiday-or-Year-leave-report>)reports.
## Reporting all Accruals in one view
If a report of **all available accruals** is needed, it can be done using the [Realized work hours ](<https://support.nepton.com/hc/en-gb/articles/360016836978-Realized-work-hours>) report. This report shows the status of all accruals on the last day of the selected reporting period.
You can also see the value of all accruals in the [Event request](<https://support.nepton.com/hc/en-gb/articles/360017787717-Event-requests>) view. This view also shows the value of the annual leave.
