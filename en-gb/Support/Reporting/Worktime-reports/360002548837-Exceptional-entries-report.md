# Exceptional entries report

It is possible to define warning notifications for various exceptional work time entries. The settings can be made either in the Working community or Setting group level. You can find more detailed information about the management of exceptional entries in [this article](<https://support.nepton.com/hc/en-gb/articles/360002560618>).
With the help of the "Exceptional entries" report, these entries can be monitored on a user-by-user basis. The report can be found in the menu **Worktime > Work hours > Reports > Exceptional entries.**
![](https://support.nepton.com/hc/article_attachments/27396101917469)
When running the report, you can specify whether the report will show all events or only approved or unapproved events.
![](https://support.nepton.com/hc/article_attachments/27396101919005)
### Including unapproved events on the report
To ease supervisors' work, the report can be run only for unapproved events. For this, a setting must be made either on the Working community or Setting group level settings. The setting can be found in the path **Worktime > Working community / Setting group settins > Work hours > Exceptional entries**:
![](https://support.nepton.com/hc/article_attachments/27396113469981)
After the setting is activated, the report can be taken out for selected time period and with the selection of "unapproved":
![](https://support.nepton.com/hc/article_attachments/27396101923741)
Click "show report" and the report loads on the screen. The report includes events that are unapproved.
![](https://support.nepton.com/hc/article_attachments/27396113476381)
The report can be imported to Excel or sent to users and/or supervisors.
![](https://support.nepton.com/hc/article_attachments/27396113478045)
**Send emails to supervisors**  
The exceptional entries report is being sent to the person's primary and secondary supervisors, as well as possible deputies of the supervisors.
**Send emails to users  
** The exceptional entries report is being sent to each user on the report, users only receive report of their own exceptional entries.
Sending reports requires a valid e-mail address in person's details in person's information in Employees section.
