# Nepton Touch: Recording an event

Show your identifier to the **RFID reader** or **enter your PIN code on the registration terminal** , depending on your organisation's practices. If logging in with a PIN code is enabled, a numeric keypad for entering the code is displayed on the screen. The registration options are defined either in the Work Community or Settings Group settings under **Worktime > Administration > Working Community/Setting Group settings > Current status > Log in possible with the recording terminal**.
After authenticating yourself at the registration terminal, you can verify that authentication was successful for the correct person by checking the initials in the top-right corner. In the example image below, the user's initials are 'YM'.
After authentication, a list of the available event types opens.
![mceclip0.png](https://support.nepton.com/hc/article_attachments/40526887503645)
Select the event you want to record as active. On the 'Assignment' tab, you can select a project assignment for the event, and on the 'Work supplements' tab, you can add a work supplement to it. When you press "Start", the event begins and the user is logged out of the terminal. 
Terminals allow entries to be made up to 2 years into the future. Entries can be made up to three months into the past.
