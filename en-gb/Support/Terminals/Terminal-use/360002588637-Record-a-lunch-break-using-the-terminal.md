# Record a lunch break using the terminal

**Whoops!**
This article has not been translated yet.
**Ruokatauon aloittaminen:**
1\. Tunnistaudu kirjauspäätelaitteelle, eli näytä oma kirjautumistunnisteesi (sininen tunniste) lukijalle.
2\. Valitse ensin **Ruokatauko-** linkki, jolloin se muuttuu harmaasta siniseksi. Tämän jälkeen valitse punainen **Aloita-** linkki**.**
3\. Muutos tallentuu ja muita toimenpiteitä ei vaadita.  
  
![Terminal1.png](https://support.nepton.com/hc/article_attachments/360010836797/Terminal1.png)
**Työn jatkaminen ruokatauon päättymisen jälkeen:**
1\. Tunnistaudu kirjauspäätelaitteelle, eli näytä oma kirjautumistunnisteesi (sininen tunniste) lukijalle.
2\. Valitse ensin **Työ-** linkki, jolloin se muuttuu harmaasta siniseksi. Tämän jälkeen valitse punainen **Aloita-** linkki**.**
3\. Muutos tallentuu ja muita toimenpiteitä ei vaadita.
