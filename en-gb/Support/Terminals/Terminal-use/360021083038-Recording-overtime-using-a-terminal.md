# Recording overtime using a terminal

This article contains instructions which will take effect when the terminals of your company have been updated to version 2.14 (on Week 6/2024 or later).
Work time exceeding regular time can be targeted to one of the accruals or to salary in the same way as in worktime calendar view.
Under heading **Work hours - > Accruals and overtime options -> Calculation settings -> Overtime** the setting _Can set overtime target on terminals_ must be set to "Yes" on either the working community or setting group settings.
![Can set overtime target on terminals setting under Calculation settings and Overtime titles](https://support.nepton.com/hc/article_attachments/15872112509341)
The compensation can be set either as hour by hour or as overtime and offer different kinds of combinations of targeting base hours and overtime hours to accruals in use or to salary. These options are under the **Visible overtime options on event creation** subtitle (note that the picture below does not list all of the possibilities).
![Example of available overtime targeting options like](https://support.nepton.com/hc/article_attachments/15874065697821)
In addition to these settings the accruals selected must also be in use under **Work hours - > Accruals and overtime hours -> Accrual is in use** title.  
![](https://support.nepton.com/hc/article_attachments/15879925507869)
It is possible to set different default overtime options for different event types under **Work hours - > Event types -> Exceptional overtime pay target default** title for _Base part (Terminal)_ and _Increment report (Terminal)_.
![](https://support.nepton.com/hc/article_attachments/15879948749213)
In addition, in the worktime role the person logging in has should have the correct settings for setting the overtime targets _Hour to hour_ and/or _Overtime_ for their own events. 
![](https://support.nepton.com/hc/article_attachments/15879925524125)
When the settings have been made in worktime, there will be a new tab "Overtime" on the Terminal when a person is starting or stopping activity.
When starting activity, the overtime tab appears after the activity type has been selected:
![](https://support.nepton.com/hc/article_attachments/15879925531933)
Similarly, when stopping activity, the overtime tab appears after the activity type has been turned off:
![](https://support.nepton.com/hc/article_attachments/15879948775197)
In the overtime view the overtime can then be targeted to one of the options available for the selected activity type.
![](https://support.nepton.com/hc/article_attachments/15879948782237)
When switching from one activity to another, it is important to look at which of the activities the selected overtime target option is targeting. It is stated above the options either for the ending activity:
![](https://support.nepton.com/hc/article_attachments/15879948791965)
or the starting activity:
![](https://support.nepton.com/hc/article_attachments/15879948796317)
To make sure the overtime is targeted for the correct activity, **it is recommended that the ongoing activity is first stopped** settings its options and **pressing the Stop button** , log in again and set the options for the starting activity only after that.
As an alternative, the overtime options can be targeted for both activities separately during the same login session in the following order:
  * unselect the stopping activity
  * select Overtime tab
  * check and, if necessary, select the overtime target for the **ending** activity (check from the title)
  * (select possible time options, project targets and supplements)
  * _recommended step:_ press Stop and log in again to make sure only the ending activity is targeted
  * select Work tab again
  * select activity type for the starting activity
  * select Overtime tab again
  * check and, if necessary, select the overtime target for the **starting** activity (check from the title)
  * (select possible time options, project targets and supplements)
  * press Start
