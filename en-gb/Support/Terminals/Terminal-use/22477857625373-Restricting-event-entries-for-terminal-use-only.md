# Restricting event entries for terminal use only

Sometimes it is desired that certain events can only be stamped with a logging terminal and this setting can be made for work community, setting group, and individual level settings as follows:
  
1\. Create a working time role to which you grant all other basic permissions except one:
![](https://support.nepton.com/hc/article_attachments/22478824344989)
2\. Prevent editing of events of the event type in the event types settings, either at the work community, setting group, or individual level:
![](https://support.nepton.com/hc/article_attachments/22478824349341)
Please note that this only works for an employee, manager or unit manager role, if the person has a role with higher privileges, such as personnel management, payroll administration or administrator, then the restriction does not work. Also make sure that the employee does not have any other working time roles that might grant the right to enter an event through mobile or the current status view.
