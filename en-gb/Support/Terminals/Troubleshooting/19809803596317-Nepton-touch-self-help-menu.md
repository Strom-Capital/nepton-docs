# Nepton touch self-help menu

As of software version 2.14.35, the terminal application includes a self help menu "?" in the top right corner of the login screen. Pressing the question mark opens the menu and provides easy access to support and troubleshooting information, Team viewer id for remote access support, and a button for restarting the terminal hardware.
