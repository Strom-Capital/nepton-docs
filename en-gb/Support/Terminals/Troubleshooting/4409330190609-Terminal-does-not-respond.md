# Terminal does not respond

Sometimes terminal can go into a state where it does not react to anything, i.e. the so-called stuck. This is a computer with an operating system and, like any computer, terminal can stop responding to feeds.
The easiest way to fix this is to [turn off the device](<https://support.nepton.com/hc/en-gb/articles/360002588737>). 
If the device does not start operating normally after start-up, contact Nepton Customer Service
