# Terminal IP address reset (For Nepton Touch devices from September 2022)

1\. Exit the terminal application by clicking from all corners in order upper left corner, upper right corner, lower right corner, lower left corner.
2\. Double-click the Static IP icon on the Windows desktop. If no external keyboard is available, click the Keyboard icon to open the virtual keyboard.
![1_Pikakuvakkeet.jpg](https://support.nepton.com/hc/article_attachments/7127415140765)
3\. If you want to check device's MAC address, in the window that opens, select Details. MAC address is Physical Address.
![MAC_address.png](https://support.nepton.com/hc/article_attachments/7400533410589)
4\. If you want to change IP address, in the window that opens, select Properties
![2_Static_IP_.jpg](https://support.nepton.com/hc/article_attachments/7237569301661)
4\. Click the Yes button
![3_Static_ip_propertises_press_ok.jpg](https://support.nepton.com/hc/article_attachments/7127415179933)
5\. Select Internet Protocol Version 4 (TCP/IPv4) and click Configure
![4._Properties.jpg](https://support.nepton.com/hc/article_attachments/7127399794845)
6\. Make the necessary settings and click OK
![5_Static_IP_setup.jpg](https://support.nepton.com/hc/article_attachments/7127399818653)
7\. Close all windows and return to the Windows desktop. Start the Terminal application from the Nepton icon.
