# Supported RFID tags with an external WaveID Plus RFID reader

It is possible to connect an external RFID reader to the [Nepton Touch](<https://support.nepton.com/hc/en-gb/articles/360003685277>) registration terminal. This article describes the types of tags that can be read by this reader. If the type of tag you are using is found on this list, support for the tag must be confirmed from the supplier regardless.
