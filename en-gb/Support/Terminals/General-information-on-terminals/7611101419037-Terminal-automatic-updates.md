# Terminal automatic updates

Nepton touch terminals are kept up to date via automatic updates. Generally, these updates will happen overnight and no actions are required from end users. More details about the different kinds of updates are documented below.
# Windows IoT updates
![mceclip0.png](https://support.nepton.com/hc/article_attachments/7610984889757)
Nepton touch devices automatically check for and install Windows updates every night, but in the event that your device shows a blue prompt like this, you can click "Another time" to defer the update until the coming night. By clicking "Restart now", the update will start immediately, during which the terminal will be unavailable for 5-15 minutes and may restart multiple times.
Please do not unplug or interrupt the device whilst it is handling an update.
Please note that Windows updates are published by Microsoft and that we have no control over their timing or content. If you encounter problems during or after a Windows update, please contact [Nepton customer support](<https://support.nepton.com/hc/en-gb/articles/7077076926237>).
# Terminal software updates
Nepton touch devices automatically check for and install terminal software and configuration updates. when needed. These require no action from you and take around 5-10 minutes to complete. During this time the terminal will be unavailable.
Please do not unplug or interrupt the device whilst it is handling an update.
