# Saarni EXP employee survey and analytics platform in Nepton

## General
Saarni EXP is an easy-to-use digital personnel survey platform which fully automated analytics leaves nothing to guesswork! Now you can measure and develop employee experience, well-being and job satisfaction directly in the Nepton service.
You can easily access Saarni EXP in Nepton by pressing the Saarni EXP button in the top menu. When you open Saarni EXP, an instructional video appears, which makes it easy to start using the service.
Every Nepton customer has access to the free Lite service level of Saarni EXP, which allows you to familiarize yourself with the use of Saarni EXP. The Saarni EXP Lite service level enables, for example:
  * Using the Saarni EXP service in Nepto's user interface
  * Seamless access rights and login: Nepton's HR administrator is automatically also the administrator of Saarni EXP
  * Personnel are updated in real time between Saarni EXP and Nepton services, eliminating all manual personnel updates
  * Automated and real-time analytics on the results of the personnel survey are directly available in Nepton's service
  * Implementation of five (5) personnel surveys for an unlimited number of employees
  * The possibility to create your own questions or use the market's largest question library and ready-made question templates
  * Multilingual surveys
  * Email and SMS surveys
  * Survey-specific analytics
  * General analytics
  * Team, location and subject area analytics
  * Admin level reporting


You can get to know the possibilities of Saarni EXP in more detail on the [More information about the Saarni EXP service](<https://saarniexperience.com/saarni-exp/>) page.
Instructions for using Saarni EXP can be found directly in the instruction video within the Saarni EXP service and in the assistant chat. You can book a Saarni EXP presentation on the [Saarni EXP website](<https://saarniexperience.com/en/>).

## FAQ
### Lite service level
You can upgrade your service level by clicking the Activate license button in Saarni EXP. You can read more information about pricing in the [Saarni EXP website](<https://saarniexperience.com/en/hinnoittelu/>).
### Roles
The administrator of Nepton is automatically also the administrator of Saarni EXP. Admins can send surveys to the entire organization and view their responses.
For users in other roles, the Saarni EXP tab displays information about Saarni EXP. Users respond to surveys via a link they receive via e-mail or SMS, for example.
Functionality for other roles can be unlocked by raising the service level.
### Privacy of survey responders
In Saarni EXP survey responses are anonymized which means that the respondent's identity is not directly visible in the service. Through analytics however it is possible to examine an individual's answers to various surveys, and examine the progress of the employee's situation. If necessary, you can contact the employee through the service and chat with them completely anonymously, creating a safe channel for continuing the conversation and preventing possible acute challenges.
### Data protection
Saarni EXP is part of the service package offered by Saarni Nepton to all our customers. Saarni EXP is a trusted service and a seamless part of Nepton. You can read more information about trusted services and data protection in these articles:
  * [What is a Trusted Services?](<https://support.nepton.com/hc/en-gb/articles/10614484104349-What-is-a-trusted-service->)
  * [Nepton data protection statement](<https://support.nepton.com/hc/en-gb/articles/360018646578-Data-protection>)


### Data shared with Saarni EXP
When the Saarni EXP service is enabled for a customer then personal data is shared from Nepton to Saarni EXP. The sharing is configured by a person with Nepton Administrator role by visiting, Nepton > Employees > Administration > Scheduled tasks, and editing the task called '**Synchronization with Nepton trusted service Kiva Work'**. The amount of information shared with Kiva work is adjusted by changing the format between **Kiva work** or **Kiva work with person groups**. The details of each format are provided below.
  1. The '**Kiva work'** format, shares only the basic customer and personal information that allows use of Kivawork within the Nepton platform. It includes all basic necessary information to keep peoples' information up to date with edits in Nepton, and to utilise Kiva work.  
  
Using this format, the following information is shared from Nepton to Kiva work:  

     * Deployment 
       * Name
       * Id
     * Person 
       * Nepton Id
       * Last name
       * First name
       * Username
       * Email
       * Phone number
       * Role
       * Primary supervisor
       * Service usage language  
  

  2. The '**Kiva work with person groups'** format, builds upon the same data shared in the 'Kiva work' format, but adds information that facilitates out-of-the-box reporting, based on organisational structure via Nepton person groups. 
This format is not yet supported by Kiva work, but will be rolled out in a future update. Please contact Kiva work support if you would like to utilise this capability.
  
Using this format, the following information is shared from Nepton to Kiva work:  

     * Deployment 
       * Name
       * Id
     * Person 
       * Nepton Id
       * Last name
       * First name
       * Username
       * Email
       * Phone number
       * Role
       * Primary supervisor
       * Service usage language
       * Person group
       * Person group code path in hierarchy
       * Person group name path in hierarchy
