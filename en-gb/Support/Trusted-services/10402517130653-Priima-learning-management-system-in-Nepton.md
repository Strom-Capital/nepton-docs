# Priima learning management system in Nepton

## General
Priima learning management system which is embedded into Nepton, enables easy and cost-effective online learning The LMS helps in developing personnel skills and abilities which are needed in the changing working life.
Each Nepton customer has access to Priima's Lite version which is free of charge. The Lite version gives users a chance to get to know Priima from its management and learning perspectives. The Priima Lite version includes:
  * seamless access and login: a Nepton administrator is automatically a Priima admin and other users are learners in Priima.
  * two current trainings which are available to all as such or they can be modified to customer's needs (topics:GDPR ja work well-being/motivation)
  * the possibility to create two new courses by using Priima's own tools


You can get to know the possibilities of Priima here: [Priima osana Neptonia](<https://store.priimalms.com/priima-neptonin-asiakkaille/>) (in Finnish).
Instructions on using Priima can be found in the [Priima Help Center](<https://help.priimalms.com/en/>).
Book a Priima demo on the [Saarni Learning website](<https://saarnilearning.fi/en/>).

## Frequently asked questions
### How do I disable Priima in Nepton?
If you do not want to display the learning content shown by default to your personnel, you can remove the users from the courses in Priima:
  * Remove your organization's group from a course: Choose course > Edit > Settings> Members > Groups> choose group "Nepton-käyttäjät" > Remove group
  * Do this for both courses GDPR-Guru and Työhyvinvointi ja motivaatio kivijalkana uuden oppimiselle


After this, the Priima content is not in use in your organization. The text There is no learning content for you. The reason might be that your organization is not using Priima learning management system or your are using another LMS is displayed when users click the Priima tab in Nepton
For more information about Priima and its course management, visit [here](<https://help.priimalms.com/en/ohje/opening-and-closing-a-course/>).
### Priima does not open in our Nepton environment
Your organisation's firewall might prevent the connection. You need allow the url https://priima.nepton.com/ in the firewall settings. This problem should be solved with the organisation's IT.

### What information is shared with the trusted Priima service?
If Priima is in use, the following information is shared from Nepton to Priima. A scheduled task has been created to do this, called Synchronization with Nepton trusted service. Information is shared when a new user is created in Nepton or a user's information has been updated. 
Deployment
  * Name


Person

  * Last name
  * First name
  * NeptonGuid
  * Service usage language
  * Employment start date
  * Employment end date
  * Phone number
  * Role
