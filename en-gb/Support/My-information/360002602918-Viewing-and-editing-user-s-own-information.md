# Viewing and editing user's own information

A user can view their own personal information in the Employees section. The information may include personal information, such as pay slips and employment contracts, if these features are in use in the deployment. The information that can be viewed may vary depending on the specifications in the deployment.
![](https://support.nepton.com/hc/article_attachments/39694968247325)
## Personal information
On the Personal information page, the user can see their own personal information and is able to update their own contact information. The user can also update additional information fields to which they have been granted the right to change. All editable fields are white, whereas locked fields are shown in grey color. The information is divided into subheadings; basic information, employment information, permissions, organization, work shift planning, additional information and identifiers. At the end of this page, the user can also change their own password.
## Documents
If documents are imported electronically into the deployment, the user can see their own files in this section. Documents can be imported in PDF format. The user cannot edit, add or delete their own documents.
## Payslips
In the Payslips menu the user can view their own payslips, if Nepton Payroll is in use.
## Deputies
In the Deputies menu deputies can be assigned to the user. Please see a separate instruction about setting a deputy [here](<https://support.nepton.com/hc/en-gb/articles/360002430678-Assigning-deputy>). 
## Additional functions
Administrator user also has an Additional functions -menu, where they manually set a new password for the user or disable the user.
