# Person group projects

Project visibility can be limited by person groups. Projects to be shown must be set for each person group, after which people assigned to the person group can see and target work to these projects.
This functionality requires that the setting “**Show only projects assigned to person in the worktime”** is activated in the project allocation settings (set to “Yes”). Detailed instructions for project allocation settings can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360002562658-Project-targeting-settings>)
  
Go to **Worktime - > Administration -> Person Groups** and select the person group from the main view to which you want to restrict project visibility.
![](https://support.nepton.com/hc/article_attachments/32470041088157)
In the view that opens on the right-hand side of the service, select the “**Projects** ” tab and add to the person group the projects that members of this group should allocate their working time to. The selected projects will appear in the **‘Selected Projects’** field.
![](https://support.nepton.com/hc/article_attachments/32470019792925)
You can select individual projects as the person group’s projects or directly choose a main project, in which case its subprojects will also be linked as projects for the person group.
Confirm the linking of projects to the person group by clicking **Save.**
