# Creating a new person group

Person groups are created in Worktime section under **Administration - > Person groups** menu option.
![](https://support.nepton.com/hc/article_attachments/32468970196637)
Adding a new person group is done from the top right corner of the view using the “**Add”** button.
![](https://support.nepton.com/hc/article_attachments/32468970198045)
In the view that opens on the right-hand side of the service, on the **“Main** ” tab, the following are defined for the new person group:
  * Name (mandatory)
  * Code (mandatory)
  * Parent Group (optional)
  * Description (optional)


![](https://support.nepton.com/hc/article_attachments/32468970200733)
It is possible to select a **parent group** for the person group from existing person groups. By assigning the desired parent group, an organisational structure can be created within the service. Person groups can also be structurally at the same level, in which case they have no parent group at all (Parent Group: Root).
The new person group is saved using the "**Add"** button.
