# Maximum compensation per event and per event type, per day

It is possible to specify the maximum compensation amount in the service:
  * Per event
  * Per event type, per day


## Maximum compensation per event
Settings for this can be found in working community or setting group settings, in _Work hours > TES > Maximum compensation per event_.
![mceclip2.png](https://support.nepton.com/hc/article_attachments/4418364293521/mceclip2.png)
Maximum compensation is set per event type. If you for example set the maximum compensation per event for remote work to be 2 hours, only up to 2 hours is compensated per remote work event.
## Maximum compensation per event type, per day
Settings for this can be found in working community or setting group settings, in _Work hours > TES > Maximum compensation per event type, per day_.
![mceclip3.png](https://support.nepton.com/hc/article_attachments/4418354123409/mceclip3.png)
If you for example set the maximum compensation per day for remote work to be 6 hours, only up to 6 hours is compensated for all remote work events on a single day.
## Assumed lunch with limits
Assumed lunch does not affect the amount of maximum compensation set in the settings described above. If for example
  * Maximum compensation per day for work event type is 8 hours
  * Assumed lunch break duration is 30 minutes
  * Day has one work event that is 8,5 hours long


8 hours would be compensated from the work event and a 30-minute assumed lunch would be generated on the day.
