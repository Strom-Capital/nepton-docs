# Absence types that contribute to work week

If an absence or unpaid absence is set to contribute towards work week with "[Event types that contribute to work week](<https://support.nepton.com/hc/en-gb/articles/25639644303645>)"-setting, this setting can be used to configure each absence types contribution towards work week.
In the example below it has been set that "Leave of absence"-type of absence does not contribute to work week. By default absence type contributes to work week if absence event type is configured to contribute to work week and unpaid absence type contributes to work week if unpaid absence event type is configured to contribute to work week.
