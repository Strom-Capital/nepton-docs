# Mass entry of worktime settings

Please note that the length of the workday, permitted work times, and excpected work times are defined in the settings of the working community level or settings group. The mass entry of worktime settings should only be used in exceptional cases!
The **Mass enter settings** function can be found in the menu:  
**Working Time → Tools → Mass enter settings**
Exceptions to the length of the workday and working time limits (permitted work times and expected work times) can be entered in bulk for workdays.
![](https://support.nepton.com/hc/article_attachments/29053413804829)
![](https://support.nepton.com/hc/article_attachments/29053413805469)
## Setting
You can make a mass entry for the length of the workday, permitted work times and expected work times.
## Recurring entry - Repeat until
You can apply the mass entry to a specific time period.
## Frequency
You can choose one of the following options for the frequency of the mass entry:
  * **Daily** : The exception is recorded for each day within the selected time period.
  * **Weekdays** : The exception is recorded only from Monday to Friday.
  * **Weekly** : The exception is recorded weekly on the weekday specified in the  _Recurring Entry_ field. The  _Repeat Until_ field defines the last date for which the exception should be recorded.
  * **Monthly** : The exception is recorded once a month on the date specified as the start date in the  _Recurring Entry_ field.


_Example_ : If the bulk entry starts on June 20 and ends on August 31, the system will add entries for June 20, July 20, and August 20.
  * **Monthly (on same weekday)** : The exception is recorded once a month on the same weekday as the start date specified in the  _Recurring Entry_ field.


_Example_ : If the bulk entry starts on Sunday, June 3 and ends on September 15, the system will add entries for each Sunday within the given time period.
  * **Yearly** : The exception is recorded once a year.


_Example_ : If the bulk entry starts on January 1, 2025 and ends on December 31, 2027, the system will add entries for January 1, 2025; January 1, 2026; and January 1, 2027.
  * **Public Holidays That Shorten the Work Week length** : You can define settings for all public holidays that automatically shorten the length of the work week.


## Remove setting
See [this article](<https://support.nepton.com/hc/en-gb/articles/360002560857-Asetusten-poistaminen-massana-EN-title-needed>) for instructions on how to remove a setting.
## Length
See [this article](<https://support.nepton.com/hc/en-gb/articles/360002560837-Workday-length-mass-entering>) for instructions on bulk entry of exceptions to the length of the workday.
## Select users
Select the individuals for whom you want to apply the change.
## Perform mass entry
Once you click the **'Perform Mass Entry'** button, the desired change will be applied to the selected individuals.
You can first make a mass entry for one person. This way you can ensure that the mass entry is made correctly.
