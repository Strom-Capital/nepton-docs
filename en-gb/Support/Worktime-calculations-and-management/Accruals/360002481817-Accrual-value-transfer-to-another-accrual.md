# Accrual value transfer to another accrual

Sometimes you may encounter a situation where you want to transfer value from one accrual to another. Typically, for example, when the balance accrual reaches the maximum limit, some of the hours are transferred to bank accrual. There is a setting in the accrual settings that allows the value to be automatically transferred to another accrual when the limit is reached. However, if you want to make the transfer manually, below are instructions for doing so. Let's use a situation where you want to transfer 30 hours from balance to bank as an example.
## Example of moving hours from balance to bank
First, the hours to be transferred are subtracted from the balance. The subtraction is done as follows:
1\. Go to the desired person's calendar view and make the changes for the day you want to make the transfer.
2\. Create a new event "Balance change". Mark the amount to be transferred as a negative value. So in this situation, when you are transferring 30 working hours to the bank, the balance change is made with the value -30.
3\. You can add a comment to the event if you want to give a reason for the transfer.
4\. Save the event.
![](https://support.nepton.com/hc/article_attachments/27944423805981)
After this you see that on the day, the value you set to be subtracted has been deducted from balance. 
![](https://support.nepton.com/hc/article_attachments/27944438005149)
Next:
1\. Go to the person's calendar view and select the day you want to make the change for.
2\. Create new event "bank change". Enter the value of the change as positive. For example, if you are transferring 30 hours from balance to bank, give 30 as the value for bank change.
3\. You may also leave a comment for the event, to explain why hours have been deducted.
4\. Save.
![](https://support.nepton.com/hc/article_attachments/27944423812509)
After this you see that on the day, the value you set to the change has been added to bank.
![](https://support.nepton.com/hc/article_attachments/27944423813405)
The same steps can be taken to transfer hours to/from any accrual in use.
