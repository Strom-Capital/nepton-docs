# Moving a settings group

A settings group can be moved to be a subgroup of another setting group in the **Worktime** section by following the path **Administration > Setting groups > Action:** **Move settings group.** Any subgroups of the setting group being moved will also be transferred under the new parent group.
![](https://support.nepton.com/hc/article_attachments/21130400462877)
  1. Select the Setting group from the Setting group menu, which you want to move
  2. Select new parent group 
  3. Select **Move**


![](https://support.nepton.com/hc/article_attachments/21130400467485)
If the parent group has an exception setting that is not intended to be used in the subgroup, a separate exception for that setting must also be created at the subgroup level.
