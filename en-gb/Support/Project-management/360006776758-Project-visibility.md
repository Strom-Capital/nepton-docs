# Project visibility

By default, projects added to the service are visible to all users. Projects can be made visible individually or by person group. This way, you can say that only certain projects are visible to members of certain groups of individuals. To enable this, the setting "Show only projects assigned to person in the worktime" must be enabled in the **Worktime > Administration > Working Community / Setting group Settings > Projects** section:
![](https://support.nepton.com/hc/article_attachments/29888736944157)
If you want all individual projects to be automatically available when they are added to the project structure, only the top-level project is added to the person or person group. If a subproject in the project structure is added manually, the new subprojects are not automatically updated to be visible to the person.
## Setting a project visible to a person
A project can be added to the person in **Worktime > Administration > Persons**. Select the person and Person's projects as action. In the left window, select the projects you want to attach to the person and click **Save**.
![](https://support.nepton.com/hc/article_attachments/29888733596189)
## Setting a project visible to a person group
A project can be set visible to an entire person group at a time, in which case it will be visible to all members of the person group. Go to **Worktime > Administration> Person groups > Person group projects**. Select the person group and select Person group projects as the action. Click on the projects you want to assign to the person group in the left window and press **Save**. Please note that the visibility of projects works on the same principle as [inheritance of settings](<https://support.nepton.com/hc/en-gb/articles/360002559178>). A project set for a parent person group is inherited downwards in the person group structure until something else is defined for the subgroup, which blocks the inheritance.
![](https://support.nepton.com/hc/article_attachments/29888733596701)
When user adds a new event both person and person group projects will be shown to them in the menu. 
![](https://support.nepton.com/hc/article_attachments/29888733599005)
