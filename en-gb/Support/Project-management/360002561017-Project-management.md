# Project management

Targeting work towards projects is available in Pro and Complete service levels.
Projects can be administrated either individually or from Project list view.
## Project list view
Project list view can be accessed by selecting **Worktime > Projects > Project list** from navigation.
List shows project's name, code, start and end dates, description, external identifier and whether project is visible in terminal (Current status view or terminal).
Actions of the view are:
  * Show ongoing, completed or all projects with radio buttons.
  * Add new projects with ADD-button.
  * Export projects to Excel with EXPORT-button. There are two options: one for current list view and one for import format. Import format can be used as a source file when [importing projects](<https://support.nepton.com/hc/en-gb/articles/360003737078-Project-import>).
  * Print projects view with PRINT-button.
  * Mark projects completed or ongoing. For this bulk edit mode needs to activated with BULK ACTIONS -button.
  * View project details by clicking magnifier-icon next to project name

## Administrating individual projects
Individual projects can be administrated by selecting **Worktime > Projects > Project** **administration** from top navigation.
Action-dropdown has three options: "Project details", "Move project" and "Add project".
### Project details
By selecting "Project details", you can select and edit project information.
External identifier field should be used to give the project an identifier which is the same as the project's identifier in an external system so that Nepton and that external system know how to identify this project.
Visible on the recording terminal can be set if you want the project to be selectable in the recording terminal, in the current status view, or in mobile. By default, the project is only displayed in the mobile view and when creating a work event in the browser (events in calendar or events in table).
Work rises can be selected here to be earned from this project if the work rise has been configured with "Earned from related projects" enabled.
For a child project to be visible in the recording terminal, all of it's parent projects need to be visible in the recording terminal as well.
Project managers field is for defining persons who can view and [approve](<https://support.nepton.com/hc/en-gb/articles/360002561477>) hours marked for a project, regardless of whether the person who has marked the hours is their subordinate or not. 
Changes are saved from the bottom of the page with Save project -button.

### Moving a project
Moving a project is done by choosing the action "Move project" when the project that should be moved is selected in the "Project" - field.
![en-40.png](https://support.nepton.com/hc/article_attachments/9221945606557)
Please note that only the lowest level projects can have events targeted for them.
Moving a project changes also report history. For example, project A was first a parent project for project B. When project A is moved away from being a parent project of project B, it won't be displayed as a parent project in reports created after the move.
