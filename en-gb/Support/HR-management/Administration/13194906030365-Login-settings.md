# Login settings

Login settings can be found in **Employees > Administration > Settings: Login**. 
![](https://support.nepton.com/hc/article_attachments/40557882186653)
The settings can be edited by Admin users. This article describes what the settings mean. Please note that settings for worktime calculations and management can be found [here.](<https://support.nepton.com/hc/en-gb/sections/360000707378-Worktime-calculations-and-management>)
## Settings
![](https://support.nepton.com/hc/article_attachments/40557882187933)
**Link to login page:** Every Nepton deployment has its own unique link, which can be used to log in directly to your community. _(This link is safe to share with all users)_
**Allow login with Nepton username/email and password:** Article about this setting can be found [here.](<https://support.nepton.com/hc/en-gb/articles/13194036455325-Preventing-login-with-Nepton-username-email-and-password>)
**Allow login with RFID and PIN on the login page (an RFID reader needs to be connected):** When active, this setting allows users to login through login page by two-phase RFID/PIN code method.
**Show mobile view for desktop users after login:** Can be set that when logging in, system opens in the mobile view by default, also when using desktop.
**Section of the service shown after login.** A list of different sections in the service, one of which can be set as the default landing page after login.
![](https://support.nepton.com/hc/article_attachments/20357276221597)
**Persons who can see their own link to classic mobile view.** A list of roles that can be selected to be able to view their mobile link in their own info.
![](https://support.nepton.com/hc/article_attachments/40557888035229)
**Allow use of "Stay signed in" for Nepton credentials on mobile devices** : Allows login on mobile devices without giving username and password again. Note! If this is in use, but the next setting is not, this info box will appear when using desktop.
![](https://support.nepton.com/hc/article_attachments/29513465362205)
**Allow use of "Stay signed in" for Nepton credentials on desktop devices** : Allows login on desktop without giving username and password again. 
**Minimum length of password:** As a default, minimun length of password is 8 characters. Password can include numbers and special characters.
**Minimum length of PIN** : [pin number/pin](<https://support.nepton.com/hc/en-gb/articles/360002430798-Manage-PIN-codes>) code can be used when logging in on terminal or using old mobile link. As a default minimum length is 4 characters.
