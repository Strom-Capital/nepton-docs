# General settings

General settings can be found in **Employment > Administration > Settings > General**. 
![](https://support.nepton.com/hc/article_attachments/40574590361885)
They can be modified by Administrators. This article describes those settings in more detail. Please note that settings related to [work time calculations](<https://support.nepton.com/hc/en-gb/sections/360000707378-Worktime-calculations-and-management>) can be found on the Worktime section.
## Settings
![](https://support.nepton.com/hc/article_attachments/40574590362269)
**Default worktime role:**[Worktime role](<https://support.nepton.com/hc/en-gb/articles/360002554338-Worktime-roles>) is a mandatory field for each person. If a person is brought to Nepton without worktime role, the role set in this setting will be set for them. One person can have multiple worktime roles.
![](https://support.nepton.com/hc/article_attachments/40574590362525)
**Default worktime setting group:** Default [worktime setting group](<https://support.nepton.com/hc/en-gb/articles/360002557357-Add-person-to-a-setting-group>) is not a mandatory field. It can be empty when a new person is added manually or via integration to Nepton. When a new person is created via the UI, or a user import, and a setting group is not provided, the new person is set to the default setting group. An exception to this is when the RESET keyword is used, then they do not get a setting group.
![](https://support.nepton.com/hc/article_attachments/40574525743773)
