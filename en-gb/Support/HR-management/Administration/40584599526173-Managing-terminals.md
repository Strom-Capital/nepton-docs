# Managing terminals

Terminals can be managed in the menu **Employees > Management > Terminals**.
![](https://support.nepton.com/hc/article_attachments/40584803203485)
In the management view, new terminals can be added to the environment, existing terminals viewed and their names and notes updated.
## Adding a new terminal
New terminals can be added to the environment under the heading **Add**. The terminal identifier, i.e. the ID, is entered in the **Terminal ID** field, and **Save** is pressed.
![](https://support.nepton.com/hc/article_attachments/40584816151069)
## Existing terminals
The terminal search can be used to view terminals connected to the environment.
![](https://support.nepton.com/hc/article_attachments/40584803204637)
The search criteria are Terminal ID, name, IP address, computer name, and terminal status (enabled/disabled). The results matching the search criteria are displayed as a list below the search criteria. The details of an individual terminal can be edited by clicking the pencil icon. The details that can be edited manually are the terminal name and note text.
