# Setting a new password for another user by admin

Admin user has the right to reset anyone's password:
Go to **Employees > Persons > Persons**. Open the right person's profile from the magnifying glass. Choose **Additional Functions > Change Password**. Type the new password in the **New Password** field. Note that HTML code (e.g., **<** followed by text) is not valid for password.
Click **Change Password**.
