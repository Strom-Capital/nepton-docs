# Changing a person's employee number

An employee number can be changed in **Employees** **> Persons.**
1\. By clicking the magnifying glass next to the correct person's row, open their complete person card. ![](https://support.nepton.com/hc/article_attachments/40182388335517)2\. Scroll down to **Identifiers** section.  
3\. Change the employee number in the Employee number field. If you are changing it to an existing employee, remember to use the [validity tool](<https://support.nepton.com/hc/en-gb/articles/360004856937>) by opening a new field from the calendar icon. Then you can set validity times for the old and new values without changing the past.  
4\. Remember to save the changes from the Save-button at the bottom of the page.
![](https://support.nepton.com/hc/article_attachments/40182388336797)
If Nepton id or external identifier 1 are in use, employee number can be updated through [scheduled person import](<https://support.nepton.com/hc/en-gb/articles/360015933397>) as well.
