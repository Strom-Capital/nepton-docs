# Password

Password can be changed either by [admin user](<https://support.nepton.com/hc/en-gb/articles/360002430418-Setting-a-new-password-for-another-user-by-admin>) or [person themselves ](<https://support.nepton.com/hc/en-gb/articles/360002596657-Changing-your-password>)on their own person’s information page or on the login page using "Forgot password?"-link.
If you log in to the system for the first time, you can set a password by clicking “Forgot password?”-link. After adding your email address, you will get more info on your email.
Admin user can define the minimum length for password in the settings. It can de defined in **Employees > Administration > Settings > Login**. As a default minimum length is 8 characters. Password can include numbers and special characters.
![](https://support.nepton.com/hc/article_attachments/20355343019805)
Note! If the logging in with username/email and password is not in use in your company, there might be some restrictions on setting password. More info [here.](<https://support.nepton.com/hc/en-gb/articles/13194036455325-Preventing-login-with-Nepton-username-email-and-password>)
