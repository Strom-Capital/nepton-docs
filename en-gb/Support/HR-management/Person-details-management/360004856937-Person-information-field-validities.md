# Person information field validities

In [person information fields](<https://support.nepton.com/hc/en-gb/articles/360004769718-Person-information-fields>), it is possible to enter values ​​that are valid from a certain date. If the validity function is not used, and the value is changed directly in the field, the value also changes the past.
Changes that are effective from a specific date must be made using the validity function in order for any previous values ​​to remain in effect. The validity function can be opened from the calendar button next to the field.
![](https://support.nepton.com/hc/article_attachments/29074636266397)
The validity function typically does not need to be used when adding a new person. The Valid from field means that the value entered is valid from that date. An empty Valid from field means that the value of the field is valid always in the past. 
By clicking on the validity function (marked in green in the picture above) a view with the information for that data field and its validity opens up. The current value is ‘Tuotantojohtaja’, which has been valid since 1.6.2025.
![](https://support.nepton.com/hc/article_attachments/29074628819357)
The value of the field can also be empty, for example for Worktime setting group. In the example below, the person did not have a worktime setting group during the period 01.01–31.05.2025. 
![](https://support.nepton.com/hc/article_attachments/29074636272925)
(The person's worktime setting group should be set to empty when person's employment ends. See [this article](<https://support.nepton.com/hc/en-gb/articles/360002575438-What-should-I-do-when-a-person-s-employment-ends>) for our instructions on how to proceed when someone's employment ends.)
If you want to save a new value that will take effect on a certain day, proceed as follows:
  1. Click on the field you want to edit. A calendar icon for the validity function will appear next to the field.
  2. Select the **calendar icon.**
  3. Click '**\+ Add'**.
  4. Enter the new value in the blank field and fill in the date to the Valid From field.
  5. Click '**Done** '.
  6. Save the changes from the **Save** -button at the bottom of the page.
