# Persons view

Persons page (Employees > Persons > Persons) allow you to view basic and quick information about persons you manage or you are a supervisor to.
## Basic view
To view more details about a person open up their details by clicking on the icon ![](https://support.nepton.com/hc/article_attachments/39726049419037) next to the target person.
More details about editing person's own information can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360002602918>)
![](https://support.nepton.com/hc/article_attachments/39726049424669)
In this view you can see list of basic information.
  * Employee number
  * Last name
  * First Name
  * Username
  * Email
  * Phone Number
  * Role
  * Unit
  * Contract start date
  * Contract end date
  * Trail period End date


This view can not be modified.
## Permissions by roles
The information displayed on the page varies depending on the role assigned to the user. You can find a more detailed description of the permissions associated with the different roles [here](<https://support.nepton.com/hc/en-gb/articles/360002425637>).
## Functions in Person view
### Filter persons
In this view you can search with the following filters:
  * Last name
  * First name
  * Username
  * Employee number
  * Personal identity code
  * RFID
  * City
  * Persons lists
  * Status (of work contract)
  * Unit
  * Persons supervisor


In addition you can choose to search only active users, active and deleted users or just deleted users.
### Add Person
Instructions for adding person can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360002427618>)
### Export person data to Excel
Persons can be exported to Excel via Export to Excel or Export to importable Excel functions. If filters have been used for the view, only the persons listed in the view are exported to excel. Further instructions for exporting persons to Excel can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360002430478>)
### Notify persons
Instructions for informing person can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360007609418>)
