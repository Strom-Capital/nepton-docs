# Persons view

Persons page allow you to view basic and quick information about persons you manage or you are a supervisor to.
To view more details about person you have to navigate to the person own information page by clicking on the icon ![mceclip1.png](https://support.nepton.com/hc/article_attachments/4696374511645/mceclip1.png) of the target person.
More details about person own information can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360002602918>)
![mceclip0.png](https://support.nepton.com/hc/article_attachments/4696237304989/mceclip0.png)
In this view you can see list of basic information.
  * Employee number
  * Last name
  * First Name
  * Username
  * Email
  * Phone Number
  * Role
  * Unit
  * Contract start date
  * Contract end date
  * Trail period End date


This view can not be modified.
## Permissions on the page:
This page is protected by rights access and only the person allowed can access to it.
More details about person roles and access rights can be found [here.](<https://support.nepton.com/hc/en-gb/articles/360002425637>)
## Fields in Person view
### Filter persons
In this view you can search with following filters.
  * Last name
  * First name
  * Username
  * Employee number
  * Personal identity code
  * RFID
  * City
  * Persons lists 
  * Status (of work contract)
  * Unit
  * Persons supervisor


In addition you can choose to search only active users, active and deleted users or just deleted users.
