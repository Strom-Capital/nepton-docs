# Service requests

The Employees section includes Service requests function, which can be used to send messages in the service.
![mceclip0.png](https://support.nepton.com/hc/article_attachments/40258054660637)
An administrator can send a service request message. HR or Payroll roles can also send messages to an individual selected from the list.
When adding a new service request, select "Message" as the type.
![mceclip2.png](https://support.nepton.com/hc/article_attachments/40258038842653)
The recipient sees the message when logging in to Nepton as an envelope icon and in the service requests function in the Own info section. 
![mceclip3.png](https://support.nepton.com/hc/article_attachments/40258054661917)
Every user can use the Own info > Service requests function to send a message without specifying a recipient. In this case, the message can be read and replied to by a person with administrator, HR or Payroll permissions.
