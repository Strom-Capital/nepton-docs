# Saving data from the service

It is possible to take out and save data from Nepton.
## Personal information
Select**Employees > Persons**.
Select Export to Excel. This will open an Excel file containing all the information entered into the service for the entire staff.
![](https://support.nepton.com/hc/article_attachments/40440616429597)If you want to sort the data, for example by units, activate the filters and fetch the data again in the view. Once the filter and new search have been applied, select Export to Excel. After this, the Excel file will only display the data according to your filter.
## Documents
If documents have been saved in persons' information, it is also a good idea to save these. Documents can be retrieved from the service one at a time.
Open the person's information. Select the Documents tab. Open the file from the Documents section.
![](https://support.nepton.com/hc/article_attachments/40440580503069)
## Event data
There are different options for saving event data. The simplest option is to select the Events in calendar report, as it provides a summary of all events for each person and, for example, balance information. More detailed event data for individuals can also be saved using other reports, such as Event listing.
Select **Worktime > Work hours > Reports**.  
  
![](https://support.nepton.com/hc/article_attachments/40440616430749)  
Under Work Hours, select **Reports**. In the reports view, select **Events in calendar**. In the **Time period** field, enter the desired time period. You can select a maximum period of two years for the report at a time. For the report type, select **Weekly information + summary**. Select users or user groups from the **Select users** section**.** If the aim is to save the information for the whole staff, it is best to select the persons in batches, not all at once. Otherwise, the report may contain so much data that downloading it will take a very long time.
![](https://support.nepton.com/hc/article_attachments/40440616432797)
Once you have selected the desired persons, select **Show report**. The report may take several minutes to load, depending on the length of the selected period and the number of persons.
When the report has loaded, you can print it directly or save it, for example, as a web page. If you save the report as a web page, you will be able to view the report even if your user credentials are no longer active.
To save as a web page, we recommend opening the reports section in a new tab before loading the report, so that you can view the page without headers.
![](https://support.nepton.com/hc/article_attachments/40440616439965)
