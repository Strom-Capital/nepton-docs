# Providing a mobile link to a person

The instructions below are only for organizations that still use old mobile link to record events. All organizations are recommended to follow new [Login to Nepton mobile](<https://support.nepton.com/hc/en-gb/articles/360002602598>) -instructions.
Only admin users can see mobile links in Nepton. Mobile links are personal and they can not be changed. 
Only send links to persons who have the right to record events in mobile. 
1\. You can find user's mobile link in Employees section in Persons. Open the person's details from the  
magnifying glass and open additional functions tab. 
2\. Click on the mobile link.
3\. Copy the user's personal link from the address bar.
4\. Send the link via e-mail to the user.
5\. The user opens the e-mail in mobile and can then save the link to the mobile device as a bookmark or shortcut.
6\. The user can now use mobile link to record events. ![mceclip0.png](https://support.nepton.com/hc/article_attachments/4412308749841/mceclip0.png)
