# Permissions overview

In Nepton, access rights are based on roles, worktime roles and permission sets assigned to the person. All of these different ways can be used to regulate what each person sees and what information they can edit in Nepton. These rights are described in more detail in their own articles.
**Roles**  
Role defines what you can do and see on areas of managing employee information and work shift planning. More about the topic on [roles](<https://support.nepton.com/hc/en-gb/articles/360002425637>).
**Worktime roles**  
Worktime role defines permissions in Worktime section. More about the topic on [worktime roles](<https://support.nepton.com/hc/en-gb/articles/360002554338>).
**Permission sets**  
Permission sets allow one person to have access to view or modify person groups' information. More about the topic on [permission sets](<https://support.nepton.com/hc/en-gb/articles/17842757043613>).
