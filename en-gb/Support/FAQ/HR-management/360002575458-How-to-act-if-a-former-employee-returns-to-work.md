# How to act if a former employee returns to work?

When a person who previously worked at the company returns to work, their previous credentials should be **restored** for their use. Currently, it is not possible in Nepton to mark multiple separate consecutive employment relationships for one person; the system only supports one employment relationship per person.
You can restore the person’s previous credentials in the **Employees** section:
  1. Enter the person’s name in the search function and select the option **Show deleted** or **Show only deleted** from the Deleted persons field. The person’s information should then be found when you select **Search**. The deleted person’s information will appear in grey.  
  

  2. You can view the person’s information by clicking the magnifying glass icon, or alternatively, you can directly select the red **Restore** button in the list view. After selecting this, the person will be restored as an active user again.  
![](https://support.nepton.com/hc/article_attachments/20546355767453)  
  

  3. Remove the end date of the person’s employment (or add a new end date in the future if it is already known) and keep the start date of the original employment. This way, the information from the previous employment will not be lost but will be found in the person’s history and will appear in reports and materials taken from these time periods.  
  

  4. Update other personal information, such as **the setting group** , to match the new employment details. Add the correct setting group to the person’s information with the start date of the new employment. Also, insert an empty value to the setting group for the period when the person was not employed, if this was not already done when the previous employment ended. This way, it will be clear when the employment was not active. Additionally, work time calculations are halted during the period when the setting group value is empty.  
![](https://support.nepton.com/hc/article_attachments/20545766658333)  
  

  5. When a person is restored to active status, **the accrual statuses must be checked** in the person's work time calendar. For example the balance may be distorted due to the restoration of the user account. If necessary, you can reset the person's balance by selecting **Add event** at the start date of the new employment in the person's calendar, and selecting**Balance reset** as the event type. Under **New value** , enter 00:00 and click **Save**.  
![](https://support.nepton.com/hc/article_attachments/20546355768477)


After restoring the employee's profile, they can log into the system again with their previous credentials. If necessary, you can change the [username](<https://support.nepton.com/hc/en-gb/articles/360002430838>) or [password](<https://support.nepton.com/hc/en-gb/articles/7025290536989>).
