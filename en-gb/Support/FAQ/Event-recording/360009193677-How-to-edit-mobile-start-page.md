# How to edit mobile start page?

The mobile view can be configured with events that are visible in the mobile page's quick start and can be used by people to record their work faster. Quick start events can be configured to be used in quick start. [You can read more about quick start events here](<https://support.nepton.com/hc/en-gb/articles/7074461491101>). If quick start events are not configured, the mobile home view has two event types that are available with the quick start for recording an event. The most common event types are Work and Lunch break. If desired, the Work event type can be changed to another.  

## Change the work event type  

The work event type displayed in quick start is defined in the service under Worktime - Administration - Working community settings - Work hours - Event types - Default event type when creating a new event. You can find it also in the corresponding section in Settings group settings. The setting below adds the Remote Work event type to quick start in Mobile View.
