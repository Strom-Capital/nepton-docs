# How to create a work event based on a planned shift?

A work event based on a planned shift can be created by clicking on the planned shift in calendar view.
![](https://support.nepton.com/hc/article_attachments/20442813286557)
Select '**Create planned event** ' from the drop-down menu.
A pop up window will open with the default values from the planned shift, such as start and end times and a possible default project. You can edit the event details and add a note for the event.
![](https://support.nepton.com/hc/article_attachments/20442828601373)
When you have the details you want, save the event by choosing 'Save'. The event is now visible in your calendar.
