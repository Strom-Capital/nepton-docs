# How to set event default project to be the planned shift's location instead of the person's default project?

When an event is created based on a planned work shift, the default project for the event can be set to be the [work shift's location](<https://support.nepton.com/hc/en-gb/articles/360015675918>) instead of the person's [default project](<https://support.nepton.com/hc/en-gb/articles/360002563098>).
Instructions for creating an event based on the planned work shift can be found [here](<https://support.nepton.com/hc/en-gb/articles/360019808237>).
In [project targeting settings](<https://support.nepton.com/hc/en-gb/articles/360002562658>) you can configurate if events are targeted to a work shift's location or to person's default project.
Configuration can be done either at the **Working community** level or at a **setting group** level.
  1. Select the level where you want to define the settings.
  2. Select **Projects**.
  3. Select the desired setting for '**Target the worktime event to the project of the planned work shift. If "no" is selected, the person's default project is used** '.  
When defining settings, use the validity function (calendar icon), through which you can activate the setting from a date of your choice.


If setting is set to 'No', Nepton uses the default project set in the person's information page in Employees-section.
