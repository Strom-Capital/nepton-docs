# How do I check a person's balance on a particular day?

If you want to check the balance of a person/persons on a certain day, you can do it using the **Hours by pay salary type** report. The report can be found in **Work time - > Work hours -> Reports ->** select the report **Hours by salary type**. Set the **time period** for the day of which you want to see the balance.
![](https://support.nepton.com/hc/article_attachments/25734715722781)
After this, you can select either one person or several people whose balance you want to check.
After selecting people, click **Show report**.
In the report, the **Balance** field tells the person's balance at the end of that period. It is possible to download the report to Excel, where extra fields can be removed if only the person's balance accumulation is to be displayed on the report.
![](https://support.nepton.com/hc/article_attachments/25734725402653)
