# How do I give a person rights to plan shifts?

The role "Supervisor" or upper role in Employees permissions, gives a person rights to plan work shifts in Planning. Upper roles are Unit manager, Salary management, HR management and Administration. In order to be able to plan shifts, a person must belong to at least one unit and to at least one location of the unit.
### If person needs rights to plan shifts, check the following things:
#### 1\. Person's unit
You can add a unit to a person in the Person's information settings in the Employees section, if he or she doesn't already have it. A person can have several units: one unit is primary and others are secondary. The primary value is only informative.
#### 2\. Person's role in Employees tab
You can define a person's role in the Employees section in the person's information settings. If a person needs only rights to plan work shifts, define role as a "Supervisor". 
![mceclip1.png](https://support.nepton.com/hc/article_attachments/4407787602705)
A person's role can be "Supervisor" even if the person does not actually work in supervisor tasks. If the person has subordinates, they need to be defined separately according to [this article's instructions](<https://support.nepton.com/hc/en-gb/articles/360005113898>).
When you have defined "Supervisor" or some other upper role for the person, the shift planning tab becomes visible in Nepton.
#### 3\. Person's membership in location of the unit
  1. Go to the shift planning tab and select the unit to which the supervisor belongs to.  
  
![mceclip2.png](https://support.nepton.com/hc/article_attachments/4407795437585)  
  
Unit selection is not shown if there is only one unit in your environment, then page is redirected straight to the location selection.   
  

  2. Select Locations tab from top of page.  
  
![mceclip3.png](https://support.nepton.com/hc/article_attachments/4407788311057)  
  

  3. Select Location, for which the person is to plan shifts.   
  
![mceclip4.png](https://support.nepton.com/hc/article_attachments/4407795999761)  
  

  4. Open the Location Persons menu  
  
![mceclip5.png](https://support.nepton.com/hc/article_attachments/4407796160401)  
  

  5. Add person to the previously selected location using the Add button. You can change the location from top of page using Select location. The person was successfully added, once person's name moves up, underneath 'Location Persons'. Adding person is not needed to save separately.  
  
Location tree follows same principle of inheritance than other settings in Nepton. If a person works in two different Locations, the person can be added to the higher level Location above these two locations. The person is then shown in both location's shift planning view.   
  
The person who is planning shifts might not be intended to be resourced to the planned shifts themselves. This can be bypassed by selecting **No** to the Location resource.
