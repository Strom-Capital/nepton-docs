# Work community does not have an active Nepton subscription

![mceclip0.png](https://support.nepton.com/hc/article_attachments/5569071660701/mceclip0.png)
If you are seeing this message it means that your contract to use Nepton service has ended with Nepton.
The Scheduled tasks (e.g. integrations) and access to Nepton API are disabled for you work community.
  * Scheduled integration tasks will not be run for your work community.
  * All public Nepton API calls are denied and following error message is returned "Access Denied: A Nepton subscription is required".


In case your Nepton service subscription is active and you are still seeing this message, contact your administrator to solve the situation.
