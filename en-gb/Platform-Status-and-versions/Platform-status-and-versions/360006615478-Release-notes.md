# Release notes

Nepton regularly releases improvements and fixes during scheduled maintenance windows. Upcoming updates are always announced on this page in advance. Detailed information about maintenance windows and service availability can be found on the [**Platform status**](<https://support.nepton.com/hc/en-gb/articles/360006554777>) page. We also recommend enabling [**article following**](<https://support.nepton.com/hc/en-gb/articles/4406604045585>)**** to receive notifications about new releases.
##  **17.11.2026** release (2.18.6)
###  __ New 
  * #### Nepton satisfaction survey 2026 H2
The survey will be presented to supervisors and administrative roles starting on 23.11 and employees on 25.11.
[Read more](<https://support.nepton.com/hc/en-gb/articles/16439727874717-Your-feedback-is-important-to-us>)
[ref 5423]


###  __ Improvement 
  * #### Performance improvements in Employees section.
[ref 4866, 5361]


###  __ Fixes 
  * #### An ended default project is no longer targeted to an event started on a Nepton Flexim terminal. 
[ref 3723]
  * #### Events started on a Nepton Flexim terminal are no longer saved to an ended project if the project selected on the terminal is ended before the event is started.

##  **10.11.2026** release (2.18.5)

  * ####  In 'Tools > Mass set event locking dates' supervisor filter only allowed selecting users based on subordinate and deputy relations, even for users with permissions to view all users. 
[ref ND-5309]
  * ####  Supervisor selection for a person no longer contains duplicates. 
[ref ND-5315]
  * #### Custom report preview did not work.
[ref ND-5318]
  * ####  Opening event editing form could cause an error if person only had permission to edit dining events. 
[ref ND-5323]
  * ####  It is now possible to register events on terminals for up to 2 years in advance. 
[ref ND-3694]


##  **03.11.2026** release (2.18.4)
###  __ Improvements 
  * ####  Fixed termination work can now be earned when an employee leaves for a part-day absence. - Absence event types that allow fixed termination work to be earned when they start can be configured with 'Fixed termination work earned when absence starts at end of work'- setting. 
[ref ND-2717]
  * ####  Person/user CSV exports now support RFC 4180 compliant value escaping to prevents exported CSV files from breaking when data values contain the field separator (;) or quote characters ("). 
[ref ND-3053]
  * ####  Fixed termination work compensation can now be limited to days where paid work is under or over a configured threshold. - Thresholds can be configured with 'Fixed compensation earned if paid work is under' and 'Fixed compensation earned if paid work is over' \- settings. 
[ref ND-3859]


###  __ Fix 
  * ####  In some cases user could not open Worktime if they didn't have permission view own events. 
[ref ND-5319]

##  **17.10.2026** release (2.18.00)
###  __ Improvements 
  * ####  Security and performance improvements as well as infrastructure updates. 
[ref ND-2208, ND-2166, ND-2163, ND-2240, ND-2221, ND-3747, ND-2211]
  * #### Groupings in person selection have been improved.
    * Grouping by payment group now correctly handles person's payment group validity dates. 
    * In person selections a person is shown only once under the same setting group. 
[ref ND-3712]
  * #### Improvements to real-time integration error handling. 
[ref ND-5073]
  * ####  Microsoft Login: Added UPN (User Principal Name) fallback support for accounts without email addresses. 
[ref ND-5246]
  * ####  BeginActivity and EndActivity webservice API methods (all versions) TerminalId field behavior improved: 
The field supports only Nepton terminal IDs but not all the required validations were performed and incorrect error messages were in certain cases given. 
[BeginActivityV2](<https://support.nepton.com/hc/en-gb/articles/6869562936221>)  
[EndActivityV2](<https://support.nepton.com/hc/en-gb/articles/6870443544477>)  
[ref ND-5176]
  * ####  Nepton Payroll: Full hourly wage history with validity periods is now sent to Palkkaus. 
[ref ND-3505]


###  __ Change 
  * ####  Improved working contract processing. Contract data is now saved only after employer approval. 
[ref ND-2862]


###  __ Fixes 
  * #### Fixes to worktime navigation items visibilities.
[ref ND-2745]
  * ####  In some cases, work hour reports page listed reports that user had no access to. 
[ref ND-2745]
  * #### Person groups can be managed with correct permissions.
    * Previously user was required to have "All higher and below level permissions" permission. Now having "Can manage person groups" permission grants access for managing person groups. 
[ref ND-2745]
  * ####  Adding service request without a process due date caused an error. 
[ref ND-5044]
  * ####  Messages added to an event request were not saved when approving event request in the Approve Event Requests view. 
[ref ND-3599]
  * ####  Mobile view did not open if a day had planned shift and only a Dining event. 
[ref ND-5188]
  * ####  Setting 'Limit Nepton API access' did not accept IP addresses with asterisk (example 83.150.*). 
[ref ND-5168]
  * ####  Project reports consistently show annual leave and the annual leave amount as hours instead of days. 
[ref ND-3697]
  * ####  Unpaid absences are not anymore shown in Project hours by person report. 
[ref ND-5245]
  * ####  Calendar Synchronisation was unable to sync shifts that originated from work schedules. 
[ref ND-4361]
  * ####  Dedicated TES overtime was not visible in day's overtime breakdown in Events in calendar view. 
[ref ND-2842]
  * #### PIN code field character limitation removed:
PIN codes longer than 6 digits can now be entered directly in the PIN code field in the person's info page as well as via user import. 
[ref ND-4831]
  * ####  Username created via user import can now be up to 100 characters long. 
[ref ND-4959]
